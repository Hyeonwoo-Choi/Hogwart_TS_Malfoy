## 3. 캐릭터

### 3.1 해리 포터 (플레이어)
목표: 평범한 6학년의 일상을 지키는 것, 드레이코의 정체를 확인하는 것. 약점: 확신이 앞선 판단(원작의 의심 성향). 성장에 따라 외형 변화(5.3).

### 3.2 드레이코 말포이 (핵심 히로인)
외형: 백금발, 날카로운 눈매, 슬리데린 교복, 곧은 자세. 소매는 끝까지 내려 입는다(복선 F-01, 실제 이유: 주문 반동 화상 흉터).

| 요소 | 설계 |
|---|---|
| 표면 | 오만, 독설, 경쟁심, 자신감 |
| 욕망 | 가문의 후광이 아닌 **자기 능력**으로 인정받는 것 |
| 두려움 | 실패, 무능, 가문의 실망 |
| 약점 | 타인에게 의존해야 하는 상황 — 도움은 곧 "무능의 증거"로 느껴진다 |
| 모순 | 독립을 원하면서 가족의 인정을 갈망 |
| 방어기제 | 비꼼, 공격, 거리 두기 |
| 핵심 갈등 | 가족에 대한 충성 vs 자신의 신념 |
| 일상 목표 | 수색꾼으로서 우승, 마법약 수석 유지, 임무 시간 확보 |

**말투**: 해리에게 비꼬는 반말(예: "~군.", "~하지 그래?"), 공식 석상에서는 정제된 존댓말. 감탄사·애교 금지. 친밀해져도 문장 구조는 유지하고 어휘만 부드러워진다.

**호칭 규칙**(감정 훅 EH-06): 드레이코→해리 "포터"로 시작. 신뢰≥40 ∧ 호감≥35 이후 사적인 장면에서 한 번 "해리"가 실수처럼 튀어나오고, RS_BOND에서 안정. 해리→드레이코는 "말포이"로 시작하며 "드레이코"로의 전환은 선택지로만 발생.

**관계 단계**: 적대 → 경쟁 → 호기심 → 인식의 균열 → 이해 → 신뢰의 시험 → 감정적 충돌 → 관계 재정의. 후퇴·단절 가능. 단계는 수치가 아니라 *사건 + 수치 조건*의 조합으로 판정(BRANCH_MAP 6장).

## 4. 감정 시스템

### 4.1 변수
드레이코→해리: **호감, 신뢰, 존경, 끌림, 질투, 경계심, 죄책감, 의존성**. 범위 0~100, 독립 관리.

| 변수 | 초기 | 변수 | 초기 |
|---|---|---|---|
| 호감 | 10 | 질투 | 15 |
| 신뢰 | 5 | 경계심 | 60 |
| 존경 | 20 | 죄책감 | 0 |
| 끌림 | 0 | 의존성 | 0 |

### 4.2 변동 규칙
1. 선택 1회 변동 기본 ±1~6, 큰 사건 ±7~12, 챕터 클라이맥스만 ±13~20.
2. 한 장면에서 같은 변수의 총 변동 상한 ±12. 일과 만남 1회 상한 ±3.
3. **성격 필터**: 드레이코는 효과를 직접 받지 않고 필터를 거친다.
   - 공개적 호의·동정 → 호감보다 *경계·의존성 반응* 우선(자존심 훼손).
   - 정면 도전·논리적 반박 → 존경/흥미 상승 가능.
   - 비겁·거짓·약점 이용 → 존경↓ 신뢰↓↓ 경계↑.
   - 사적이고 조건 없는 도움 → 신뢰↑ 그러나 의존성 경고 구간 진입 가능.
4. 7일(게임 내) 이상 접촉이 없으면 경계 +2. 해결되지 않은 갈등은 감쇠하지 않는다.
5. 수치는 UI에 표시하지 않는다(개발용 `?debug=1` 오버레이만 허용).

### 4.3 상호작용 규칙 (말이 되는 조합)
| 조건 | 결과 |
|---|---|
| 호감 높음 ∧ 신뢰 낮음 | 가까이 하면서 속은 숨김. 약점 장면에서 방어적 |
| 의존성≥40 ∧ 신뢰<40 | 반발(밀어내기·도발). 의존을 부정하려는 행동 |
| 의존성≥40 ∧ 신뢰≥55 | 도움 요청이 가능해짐 |
| 질투≥30 ∧ 해리가 타 인물과 친밀 | 해당 인물을 향한 비꼼 대사 추가(소유욕 표현 금지, 경쟁심으로 표현) |
| 죄책감≥40 | 케이티 관련 장면에서 회피·침묵. 해리가 몰아세우면 분노로 전환 |
| 끌림 상승 | 호감이 아니라 *존경·호기심* 이벤트에서만 발생 |

**감정 훅(수치가 실제 대사·행동을 바꾸는 지점)은 BRANCH_MAP 4장의 EH-xx로 관리하며 QA 테스트 케이스가 된다.**

## 5. 일과 및 성장

### 5.1 시간 구조
하루 = 수업(자동) + 슬롯 3개(오후1 / 오후2 / 저녁) + 야간(통금 후, 위험 판정). 챕터마다 자유 일과 일수를 지정. 챕터 1은 야간 비활성(메인 이벤트 전용).
진행: **메인 스토리 → 스토리 구간 종료 → 자유 일과 → 다음 메인**. 일과 중 특별 이벤트는 해당 슬롯을 소비하고(`free:true`는 예외), 종료 후 남은 슬롯으로 복귀한다.

### 5.2 능력치 (0~100)
초기: 지성40 체력40 마법실력45 통찰력35 사교성35 의지력40. 활동 1회 +1~3(70 이상은 +1). 활동: 공부(지성) / 마법 훈련(마법·의지) / 퀴디치(체력) / 대화(사교·통찰) / 휴식(의지 회복, 피로 해소) / 특별 이벤트.

높은 능력치는 보장이 아니라 선택지를 *넓히면서 대가를 만든다*.

| 능력치 | 효과 | 대가 |
|---|---|---|
| 지성 | 논리적 반박 선택지 | 드레이코가 "말만 앞선다"고 느낄 수 있음(실행이 없으면 존경 감소) |
| 체력 | 퀴디치·물리적 대응 | 과신 시 위험 판정 실패 시 부상 |
| 마법 실력 | 대결·대응 선택지 | 드레이코의 경쟁심 자극(경계↑) |
| 통찰력 | 단서를 일찍 알아챔(KN 획득) | 일찍 알수록 드레이코가 해리를 위협으로 인식 |
| 사교성 | 소문·조연 관계 이득 | 소문 확산(`FLAG_RUMOR_ACTIVE`)과 사생활 노출 |
| 의지력 | 시간제한 선택 안정, 충동 억제 선택지 | 고집 선택지로 관계 경직 가능 |

선택지 노출 규칙: 능력치 조건 선택지는 조건 미충족 시 **표시하지 않는다**(해리가 떠올릴 수 없는 행동). 조건 문구는 UI에 표기하지 않는다.

### 5.3 외형 변화
상위 능력군(학구형=지성·통찰, 전사형=체력·마법, 사교형=사교·의지)이 60 이상이면서 다른 군보다 10 이상 높으면 외형 상태 VS-학구/전사/사교 전환(그 외 균형형). 변화는 챕터 경계에서만 적용하고, 드레이코·헤르미온느 등이 **한 번씩** 대사로 인식한다.

## 6. 지식·일관성 규칙

1. 장면 대사는 해당 인물의 열(T 표)에 있는 정보만 사용한다.
2. 해리가 KN_ 플래그를 갖지 않은 사실은 선택지·대사에서 언급 불가.
3. 해결된 갈등은 `resolved` 처리하며 이유 없이 반복하지 않는다. 해결되지 않은 갈등(`FLAG_TEST_FAILED`, `FLAG_RON_STRAINED` 등)은 **명시된 복구 이벤트**로만 해소된다.
4. 약속·배신은 기록(`promises[]`)하며 후속 장면의 필수 참조 대상.
5. 새 장면 작성 전 체크: 장소-시간(3.2 일정), 인물 지식, 미해결 갈등, 호칭 단계.

### 7.2 스크립트 노드 규격 (요약)
노드 종류: `line`, `choice`, `set`(플래그/지식), `delta`(감정·능력치), `if`, `goto`, `expr`(표정), `bg`, `routine`(일과 시작), `lock`/`unlock`(지도), `timed`, `end`.
감정 반응 대사는 변형으로 작성한다.
```json
{"type":"if","cond":"draco.trust>=40","then":"c8_letter_open","else":"c8_letter_burn"}
```
표정(`expr`)은 선택 결과 직후·감정 훅 달성·챕터 핵심 대사에서만 사용한다.

## 8. 연출 규칙

- 감정은 **설명하지 않고 행동·시선·침묵·대사로** 보여준다. ("호감 상승" 서술 금지)
- 표정 10종: 평온 / 무표정 / 비웃음 / 흥미 / 당황 / 분노 / 불안 / 슬픔 / 결심 / 미소. 평균 10~15 대사당 1회 이하. 진심 미소는 Ch8 이전 최대 1회.
- 유머·긴장·갈등·휴식을 챕터당 균형 배치(조연 일상 장면 필수).
- 로맨스 진행 상한: 챕터 7 이전에는 호감 표현 금지(호기심·존경 반응만). 손 맞잡기·포옹은 신뢰≥55, 고백은 신뢰≥70 ∧ 끌림≥55, 키스는 `RS_BOND`에서만.

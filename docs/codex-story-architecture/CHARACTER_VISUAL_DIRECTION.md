수량만으로 동등성을 주장하지 않는다. `ev3_b_shoulder`는 지니가 결정권을 갖고 론이 걱정을 자기 말로 정리하는 공동 장면으로 설계한다. Ron 단독 CG 추가 여부는 전체 제작 예산과 Ch8·Ch11의 독립 사건을 본 뒤 판단한다.

## 복장·환경 변형

- 교복: 수업/공개 행사. 관계가 아니라 날짜·활동으로 결정한다.
- 퀴디치 장비: 지니·드레이코·론의 능력과 피로를 보여 준다. 젖음·흙·붕대는 해당 경기/훈련 결과가 있을 때만.
- 사복·겨울 외투: 호그스미드·방학·사적 휴식. L3의 신호로 자동 사용하지 않는다.
- 비·바람: 머리·망토·호흡의 방향을 사건 원인과 맞춘다. 몸의 노출보다 불편과 선택을 보여 준다.
- 마법광: 균열은 흰색 과노출, 잔류 마법은 검보라, 안전한 벽난로는 따뜻한 주황으로 기능을 구분한다.

## 카메라 규율

1. 갑작스러운 접근은 원근 변화와 잘린 배경으로 표현하되, 접촉 전 멈춤과 상대 반응을 같은 컷에 둔다.
2. 클로즈업은 눈·손·핵심 물체 중 하나만 강조한다. 신체 일부만 소비하는 크롭은 피한다.
3. 해리가 모르는 감정은 인물의 눈·호흡·손동작으로만 제시한다.
4. 질투는 목격자 시선선과 원인이 한 프레임에 있을 때만 쓴다. 전언은 다음 장면의 대화로 처리한다.
5. 특별 장면은 인물마다 다른 주도성을 갖는다: 헤르미온느는 범위 합의, 지니는 참여 제안, 루나는 침묵 공유, 판시는 조건 제시, 드레이코는 통제권 회복.

## 자산 패키지 권장

- 기본: 16:9 원화, 배경 분리, 인물/전경/마법광 3레이어, 중앙 안전 영역.
- 변형: 눈·입·손 레이어 또는 최대 2개의 완성 프레임. 수치 조합별 원화 증식은 금지한다.
- 드레이코: `base/illusion`과 `true` 파일군을 명확히 분리하되 파일명은 중립화한다.
- 갤러리: 스포일러 없는 잠금 상태, 경험 후에만 제목·캡션·썸네일 공개.

## Ch8~14 장기 시각 주도권

| 인물 | 후반 독립 행동 | CG에서 보여 줄 주도권 | 피할 표현 |
|---|---|---|---|
| 헤르미온느 | 검증 기준·보호 절차·신고 범위를 정함 | 자료를 소유하고 공개 범위를 직접 표시 | 해리에게 답을 건네는 보조자 구도 |
| 지니 | 선발·당직·경기 지원을 선택함 | 점수표와 빗자루를 직접 들고 역할을 배정 | 해리의 선택을 기다리는 관중 구도 |
| 루나 | 지도·증언의 사용 범위를 정함 | 관찰 지점과 공개하지 않을 구간을 직접 가리킴 | 직관만 제공하고 사라지는 신비 장치화 |
| 판시 | 전언·보호·거처 조건을 협상함 | 서명·열쇠·주소를 건네기 전에 멈추고 조건을 말함 | 드레이코의 감정 대리인으로만 배치 |
| 드레이코 | 임무·공개·도움 수락을 자기 이름으로 결정함 | 편지·펜·지팡이를 스스로 놓거나 거둠 | 취약성 노출을 자동 친밀 보상으로 처리 |
| 론 | 훈련·호송·우정의 한계를 말함 | 빈 자리와 훈련 수치를 자기 말로 바꿈 | 질투만으로 행동하는 방해자 구도 |

Ch13 병행 CG는 한 장의 영웅 중심 군집 구도보다 인계·호송·봉쇄·이동·탑의 서로 다른 손과 시선선을 사용한다. 해리가 없는 장소는 사후 흔적이나 증언으로만 보여 주며, 탑 내부 실제 대화는 현장 참여가 확정된 경로에 한정한다.

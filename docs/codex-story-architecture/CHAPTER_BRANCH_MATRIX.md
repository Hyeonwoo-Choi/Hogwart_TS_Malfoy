# CHAPTER_BRANCH_MATRIX — 사건 진입·선택·결과표

> 설계용 문서 번호 `Cnn-A~E`는 엔진 장면·선택 ID가 아니다. A~E의 뜻은 챕터마다 바뀐다.
> 각 행은 고유 도입→조사→충돌/반전→결정→즉시 결과→후속의 제작 계약이다. 공통 장면은 [MASTER](STORY_MASTER_BRANCHES.md), 상태 원천은 [REQUIREMENTS](STORY_FLAG_REQUIREMENTS.md).

## 진입·선택 공통 계약

- 표의 진입은 **대안 관계**다. 과거 단서가 없어도 당일 공개 훅으로 진입한다. 높은 수치는 추가 방법만 열며 메인 경로를 잠그지 않는다.
- 최초 사건을 조사하기 전에는 인물 이름·수치·루트명을 선택지에 표시하지 않는다. 정체를 알아본 뒤의 대사에서는 자연스러운 호칭을 허용한다.
- 한 챕터에서 주경로 하나, 선택적 보조 사건 하나만 긴 장면으로 재생한다. 겹친 일정은 선택 전에 장소·시각으로 알리며 성공률을 알리지 않는다.
- 진입 전 이력은 사건을 바꾸고, 단순 호감은 사건을 발생시키지 않는다. 새 경로에서는 인물이 스스로 제시할 일이 있어야 한다.
- 공통 합류는 날짜 전환이지 결과 초기화가 아니다. C02 이외의 상세 수치·최종 선택 ID는 구현 회차에서 지정한다.
- 불참·거절 시 고유 행동은 [CHARACTER_LONG_ARCS](CHARACTER_LONG_ARCS.md)의 독립 시계대로 진행하며 다음 공지·대화로만 알린다.

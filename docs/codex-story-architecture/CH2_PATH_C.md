# Ch2 C — 지도에 없는 계단

> [상위](CH2_DETAILED_STORY.md). 통로는 해리의 단서인 동시에 다른 학생의 생활로다. 등장 학생은 성인 AU다.

## C1. 빠진 계단 번호 / 9/16 월 방과 후 / 성 안뜰 / 해리·루나

목적: ‘루나를 고른다’ 대신 안내판에서 사라진 계단 번호를 조사하게 한다. 이전 반사광 이력은 먼저 알아보는 한 줄로만 사용. 연출 `show null`로 번호판부터 묘사한 뒤 루나가 등장한다. 진입 선택은 번호를 종이에 옮기기/안내판 뒷면 확인하기.

나: 사십 다음에는 사십이였다. 나사 구멍은 번호 하나가 더 있었던 자리에 남아 있었다.
루나: “계단이 사라진 건 아니야. 번호가 빠졌어.”
해리: “둘이 다른 일이야?”
루나: “길이 없어지면 못 가. 이름이 없어지면, 가는 사람이 잘못한 것처럼 보여.”
나: 그녀는 안내판 아래에 종이를 대고 구멍 위치를 눌러 찍었다.
해리: “어디로 가는 길인데?”
루나: “내가 본 데까지 보여 줄게. 나머지는 아직 몰라.”

결과: 안내판 누락과 루나의 증언을 분리해 기록한다. 성의 숨은 공간 전체나 임무는 모른다. 관찰을 거절해도 27일 공개 지도 정정 요청을 통해 기본 결론에 참여할 수 있다.

## C2. 태피스트리 뒤 / 같은 날 / 5층 복도 / 둘

목적: 기존 Q-03의 입구 발견·직접 조사·일방 신고를 실제로 다른 관찰로 유지한다. 연출 `bg library`를 기존 복도 대체 배경으로 쓰고 텍스트로 장소 고정, `light dim`과 `cue pause`만 사용. 새 통로 배경은 필수가 아니다.

나: 천을 들자 바람이 손목을 스쳤다. 계단의 첫 칸만 보였다.
루나: “여기. 난 지난번엔 여기서 돌아갔어.”
해리: “혼자 더 가지 않은 건 잘했어.”
루나: “잘한 건지 물어보진 않았는데. 그래도 같이 온 건 좋아.”
나: 나는 손을 계단 벽에서 뗐다. 입구에 묶인 실은 내 것이 아니었다.
해리: “다른 사람도 쓰나 봐.”
루나: “응. 그래서 우리 지도만 보고 막으면 안 될 것 같아.”

선택: Q-03 A/B/C의 의미를 유지한다. A만 내부 문양·온기를 직접 확인. B는 입구 표시만. C는 신고·봉쇄·허락 없는 대리 발언의 갈등을 남긴다.
이미 Q-03 A에서 조사했다면 뒤 장면에서 같은 조사를 새 행동·보상으로 반복하지 않는다. KN·OB 최신 분리는 그대로 유지한다.

## C3. 누구의 지름길인가 / 9/18 수 오후1 / 공개 복도 / 둘·다른 학생

목적: 통로 사용자를 단서 제공 장치가 아니라 생활 주체로 보여 준다. 이 학생은 무거운 장비를 들고 우회로로 가다가 해리 일행에게 도움을 요청한다. 진짜 모습을 지닌 드레이코를 목격시키지 않는다.

학생: “이쪽 닫혔어요?”
나: 가방 끈이 손가락을 눌러 하얗게 만들고 있었다. 나는 먼저 바닥에 놓으라고 손짓했다.
루나: “여길 자주 지나가?”
학생: “장비실까지 덜 돌아가니까요. 안쪽은 좁아서 둘이 못 지나가요.”
해리: “위험한 건 못 봤고?”
학생: “위험한 거요? 문 닫히는 소리는 들었어요. 그래서 저녁엔 안 가요.”
나: 루나는 ‘안전’이라고 쓰려던 칸을 비워 두었다.

새 정보: 통로는 실용적인 길이지만 소리를 들었다는 전언은 안전 보증이 아니다. 선택은 장비를 같이 운반/길 안내 담당을 불러 줌. 미참여여도 인물은 장비를 내려놓고 도움을 구해 이동한다.
결과: 물건을 드는 보호 행동은 낯선 학생의 몸을 잡을 이유가 아니다. 즉각 위험을 막는 최소 제지 후에는 의사를 다시 묻는다. 목격자·장소가 없는 관계 반응을 추가하지 않는다.

## C4. 안쪽에 그릴 수 없는 칸 / 9/27 금 오후2 / 호수→복도 / 해리·루나

목적: 기존 ap2_secret/Q-07의 낮 관찰과 지도 정정을 하나의 행사로 묶는다. 왕복·확인은 행사 소요 안에 포함하고 지도로 복귀한 뒤 시간을 다시 빼지 않는다. 봉쇄 이력은 외부에서 허가된 범위만 관찰한다.

나: 루나의 지도에서 선이 중간에 끊겼다. 선 끝에는 물음표도 없었다.
해리: “모른다고 써 두면 되잖아.”
루나: “여기가 어딘지 아는 척하고 싶지 않아서.”
나: 나는 같은 모양의 빈칸을 옆 종이에 그렸다.
해리: “내가 가 본 데는 여기까지야.”
루나: “그럼 그 선은 네가 그어 줘.”
나: 내 선은 그녀의 선보다 짧았다(입구만 확인). / 벽의 꺾인 자리를 한 번 더 그렸다(내부 확인).

갈등·반전: 좁은 계단은 지름길이지만 들것·장비 운반에는 부적합하다. 숨은 길을 찾았다는 성취가 대피의 만능 해결책이 되지 않는다. Ch9 실제 대피 훈련에서 이 한계를 회수한다.
현장 불참 시 지도 정정 공지를 읽고 출입구 상태만 정리한다. 내부 감각이나 둘이 숫자를 같이 센 관계 이력을 받지 않는다.

## C5. 공개할 선 / 최종 결정

해리가 아는 것: 본 범위의 위치·사용자 전언·계단 폭, 실제 조사했을 때만 내부 문양/온기. 신체 변화·캐비닛·목표는 모른다. 기존 신고 이력에 대한 화해는 별도 책임으로 남는다.

| 표시 문구 | 즉시 사건 결과 | 관계·지식·상태 | 다음 장·복선 회수 |
|---|---|---|---|
| “출입구만 표시하자.” | 공개 안내는 입구와 우회로까지, 위험 여부는 미확인 표시 | marked, 이미 본 사실은 지우지 않음. 수첩과 공개 지도의 범위는 다름 | C03-C 우회 안내·C07-C 출판권 |
| “확인한 안쪽 부분을 지도에 옮긴다.” | 실제 확인한 범위만 기록. 미조사면 허가받은 한 층 실측으로 문구 변경 | surveyed, 허가/직접 관찰이 없으면 이 방법을 숨김. 기본 선택은 남음 | C04-C 귀환 길·C09-C 들것 폭·C13-C 봉쇄 |
| “이 구간은 막아 달라고 함께 요청하자.” | 루나·사용자 의견을 받은 안전 신청, 폐쇄되면 우회 비용 발생 | closed, 이전 일방 신고는 자동 면책되지 않음 | C03-C 허가 협의·C11-C 사용 범위 |

반응, marked: 루나 — “빈 곳이 틀린 건 아니네. 아직 안 그린 거니까.”
surveyed: “네가 본 선은 네 이름 옆에 둘게.” / closed: “대신 돌아가는 길도 그리자. 막는 사람도 길 하나는 남겨야 하니까.”
감정 적용은 반응과 gate 뒤. 협업 동의가 손잡기 동의는 아니다. 이전 신고 갈등이 있다면 안내판 정정·상대 응답을 먼저 재생한다.

## C6. 지도 바깥 / 9/28 밤→29 아침

한밤의 7층 사고에는 루나·통로 사용자가 오지 않는다. 내부 조사 이력은 해리의 접근 방법만 바꾸고, 폐쇄되었으면 허가 없이 봉쇄를 통과했다고 쓰지 않고 기존 정문 계단으로 간다.
나: 지도를 접었다. 남에게 보여 줄 수 있는 선과 내가 오늘 걸은 선은 같지 않았다.
29일 루나는 공개 안내표의 상태만 확인한다. 해리는 개인 사고를 지도에 표기할지 미루며 신체 비밀을 함부로 기록하지 않는다.
Ch3에는 우회로 불편·좁은 통로의 사용권이 남는다. 길을 막았다고 조사를 전부 실패 처리하지 않고 합리적인 안전 결정을 인정하면서 비용도 보여 준다.

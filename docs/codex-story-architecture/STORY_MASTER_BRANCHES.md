## 불변 조건·분기 방식

성인 AU·등장 학생 전원 만 18세 이상·해리 1인칭. 드레이코는 9/28 밤까지 남성이고 캐비닛 마법+프로테고 충돌로 영구적 여성 신체가 된다. 해리만 목격한다. 공개 기본은 환영, 진짜 모습은 명시된 사적 장면만. 치료·원상복구는 주제가 아니다. 자기수용은 애정과 다르다.
F-01 흉터는 Ch6, 나르시사·목걸이의 목표·임무는 기존 진실표의 단계적 공개를 지킨다. 작가가 아는 정보를 해리·수첩·다른 인물에게 자동 지급하지 않는다.
챕터별 주경로 하나는 `사건→조사→대립→새 정보→비용 있는 결정→고유 결말`을 가진다. 보조 사건 하나까지만 긴 장면으로 재생하고 나머지는 인물이 독립 진행한다. 해리는 나중의 공지·허가된 전언으로만 이를 안다.
경로는 매 챕터 새 훅으로 바꿀 수 있다. 이전 경로는 접근권·정보·비용·약속을 바꾸되 다음 사건을 독점하지 않는다. 높은 능력치는 추가 방법만 열고 기본 진입은 항상 둔다.
공통 합류는 시간 진행이다. 기록·부상·공저·통로·거래의 결론은 남는다. 연애 동의는 사건 협조·정보 공개 동의와 별개다. 질투에는 실제 목격/전언과 관계상 기대가 필요하다.
Ch2의 사고는 고정 사건이지만, Ch13의 모든 플레이를 탑의 개인 대화로 모으지 않는다. 학교 안전·친구들의 성과는 드레이코 관계와 독립 결산한다.

## Ch1 — 9월의 기차 / 9/1~8

- 중심 갈등: 익숙한 학교 안에서도 누군가는 자기 자리와 시간을 증명해야 한다. A 각주 / B 겹친 연습표 / C 반사광 / D 쪽지 / E 늦은 불빛. 기존 H-08 키와 선택 이력은 보존한다.
- 공통: 소매 F-01, 손떨림 F-02, 추락 K-03, 9/7 K-04, 초대장. 인물: 연구 근거·팀 연습권·관찰 기록·초대 명단·키퍼 평가를 해리 없이도 준비한다.
- 주요 장면, 경기장 계단: 나는 시간표 두 장을 겹쳤다. 수정된 잉크가 같은 칸에 번져 있었다. 지니가 종이를 눌렀다. “잘못 적힌 건 시간이야. 내가 온 게 아니고.”
- 선택과 대가: 자료 반환/보관, 공동 시간표 정정/자기 몫 확보, 위치만 기록/성급한 지목. 사전 거절과 말없는 불참을 구별한다. 중립 H-08 F도 정상 완주한다.
- 이월: Ch2 조사 비용·첫 질문·자료 접근. 회수: Ch3 약속, Ch6 F-01. 완화는 론과 초콜릿 카드 교환으로 둔다.

## Ch2 — 균열 / 9/16~29

- 중심 갈등: 같은 이상을 학교는 사고, 학생은 방해, 개인은 비밀로 부른다. A 연구·기록 / B 경기·경쟁 / C 통로·안전 / D 거래·증언 / E 물질 소실의 흔적.
- 공통: 9/19 만찬, 9/25 수요일 4층 폭발, 9/28 경기·라커룸 충돌·밤 사고, 9/29 환영 흔들림. 후반 자유 일과는 실제 코드대로 9/26~27이다.
- 주요 장면: 나는 방패를 세웠다. 문짝 너머로 빛이 뒤집혔다. 바닥의 지팡이는 두 개였고, 대답해야 할 사람은 일어나지 못했다.
- 선택과 대가: 증거 보관권·훈련 중단·통로 공유·서명 책임·시료 인계. 경로마다 조사 결말이 먼저 나고 공통 사고의 목격 사실은 그대로다.
- 이월·회수: Ch3 진술과 공동 징계, Ch4 증거력, Ch5 안전 대응, Ch8 출처와 공개 범위. 상세 대사·상태는 별도 원고 참조.

## Ch3 — 벌점 / 9/30~10월

- 중심 갈등: 같은 벌이 같은 책임은 아니다. A 징계 기록 / B 복귀 심사 / C 우회 통행 / D 증언 철회 거래 / E 환영 유지와 사생활.
- 공통: 라커룸 충돌의 공동 징계, 빌렸을 때만 망토 반환, 과제 공지. 드레이코는 E를 고르지 않아도 스스로 환영을 관리한다.
- 주요 장면, 트로피실: 론이 걸레를 짰다. “네가 대신 말했다고 내가 안 했던 일이 없어지진 않잖아.” 나는 양동이 밖으로 떨어진 물부터 닦았다.
- 선택과 대가: 공동 진술 정정/각자 제출/자기 책임 축소. 보호한 증언의 범위가 원본 제출과 충돌한다. 말로만 사과해도 벌점 기록은 지워지지 않는다.
- 이월·회수: 기록 신뢰·훈련 제한·우회 허가·사생활 약속→Ch4 접근, Ch7 공동 작업, Ch9 시험. 론·판시는 비개입 시 자기 이름으로 정정한다.

## Ch4 — 일곱 번째 층의 벽 / 11월 초

- 중심 갈등: 문을 안다는 것과 열 권리가 있다는 것은 다르다. A 수리 대출 / B 관중석 공사 / C 필요의 방 / D 유통표 / E 지연 반응.
- 공통: 해리는 이미 ‘벽에 문이 있었다’를 안다. 방·캐비닛·부분 작동은 직접 관찰한 경로만 안다. F-03/04/07 회수는 정보 출처에 따른다.
- 주요 장면, 문 앞: 사과 하나가 발끝으로 굴러왔다. 한쪽이 베여 있었다. 나는 주머니 속 사과를 꺼냈다. 아직 베어 물지 않은 것이었다.
- 선택과 대가: 반환/물증 인계/비접촉 기록. 복제·통로라고 미리 단정하지 않는다. 방 진입을 거절해도 공사·유통 사건의 독립 결론을 얻는다.
- 이월·회수: 증거 접근·안전 표식·가게 연결·KN_CABINET 직접 지식→Ch5 포장지, Ch8 출처, Ch10 F-09. 지니는 공사 손실을 자기 이름으로 협상한다.

## Ch5 — 목걸이 / 11월 지정 호그스미드 주말

- 중심 갈등: 사람을 살리는 순서와 범인을 찾는 순서. A 인계 기록 / B 구조 / C 저주 접근선 / D 운송·소문 / E 목격자 보호.
- 공통: 케이티 접촉과 이송. 구조 행동에 따라 피해 경과가 달라지지만 낮은 수치로 구조 전체가 잠기지 않는다. 실제 목표는 아직 확정하지 않는다.
- 주요 장면, 눈길: 론이 내 손목을 잡았다. “그 손으로 잡지 마.” 그제야 맨손이 보였다. 지니가 벗은 망토가 눈 위로 펼쳐졌다.
- 선택과 대가: 안전한 접촉을 기다림/지원 인력 모집/인계자 추적 위임. 범인 이름을 먼저 지목하면 증인의 안전과 동료의 신뢰를 잃는다.
- 이월·회수: 부상 경과·F-10 포장·고발·진술 동의→Ch6 사과, Ch8 T-04, Ch11 공개 범위. 판시는 기숙사 전체의 낙인을 자기 주장으로 반박한다.

## Ch6 — 겨울의 소매 / 12월

- 중심 갈등: 사실을 알고 싶은 마음이 몸에 손댈 권리는 아니다. A 실험 동의 / B 복귀 경쟁 / C 소각 흔적 / D 방학 초청 / E 소매의 사실.
- 공통: 학기말·크리스마스·F-11. 표식 없음과 반동 흉터 F-01은 E 및 실제 확인 경로만 안다. 다른 경로는 모른 채 진행해도 된다.
- 주요 장면, 빈 교실: 나는 손을 뻗다가 멈췄다. 말포이가 그 손을 보았다. “질문부터 해. 네가 순서를 모를 리 없잖아.” 나는 지팡이를 내려놓았다.
- 선택과 대가: 허락 요청/확인하지 않음/강제 접촉. 강제 확인은 사실을 얻어도 관계와 자료 접근을 잃는다. 친밀 장면은 사과의 보상이 아니다.
- 이월·회수: 신체 경계·선물 수락/거절·소각 시간→Ch7 권한, Ch9 비밀 시험, Ch12 폭로 범위. 지니와 론은 해리 없이도 복귀 경쟁을 한다.

## Ch7 — 공동 과제 / 1월

- 중심 갈등: 같이 만든 결과에 누구의 이름을 쓰는가. A 공동 논문 / B 전술 / C 지도 출판 / D 예산 / E 평온의 약.
- 공통: 발표회. E는 기존 K-13을 재사용할 수 있으나 전 경로에게 개인 과제를 강제하지 않는다. F-12는 들은 경로에서만 기록한다.
- 주요 장면, 발표대 뒤: 판시가 내 이름표를 뒤집었다. 뒤에는 수정 목록이 붙어 있었다. “이쪽은 네가 고칠 것. 저쪽은 내 것.”
- 선택과 대가: 원자료 공개/공동 검수/혼자 발표. 타인의 이름을 지우면 높은 성적이어도 공저는 끝난다. 능력이 낮으면 범위를 줄여 완수한다.
- 이월·회수: 성과 소유·재현 자료·역할 배분→Ch8 부탁, Ch10 대안, Ch14 진로. 미선택 인물도 작은 자기 발표를 남긴다.

## Ch8 — 도착한 편지 / 2월

- 중심 갈등: 편지를 읽는 사람과 위험을 감당하는 사람이 다르다. A 검열 회신 / B 론의 슬럼프 / C 잃어버린 노트 / D 초대 조건 / E 나르시사 편지.
- 공통: 우편 검사 강화. A/D의 일반 검열과 E의 가족 인질 사정을 구별한다. 나르시사 위험을 전원에게 자동 공개하지 않는다.
- 주요 장면, 식탁: 론은 ‘포터 추천’을 지웠다. 종이가 얇아졌다. “네가 싫어서가 아니야. 내 이름 옆을 비워 두려고.” 나는 잉크병을 밀었다.
- 선택과 대가: 열람 허락/봉투만 조사/몰래 펼침. 검열을 피해 얻는 정보에도 출처가 필요하다. 루나는 노트 회수 대신 제보자 안전을 택할 수 있다.
- 이월·회수: 검열 증거·자립한 동료·목표 추정·공개 범위→Ch9 약속, Ch10 위험, Ch11 협력. F-02/06/08/10/11은 보유 증거로 회수한다.

## Ch9 — 시험 / 3월

- 중심 갈등: 믿음을 시험한다며 사람을 도구로 만들 수 있는가. A 자료 검증 / B 선발 책임 / C 대피 훈련 / D 거짓 전언 / E 비밀 시험.

- 선택과 대가: 기준 공개/몰래 검증/참가 거절. 거절은 자동 단절이 아니다. 헤르미온느도 자기 검증 방식이 기만이었는지 답해야 한다.
- 이월·회수: 절차 정당성·지휘 경험·유출 이력→Ch10 협력, Ch12 공개, Ch14 신뢰. 판시는 해리가 없어도 거짓 전언을 거부하거나 자기 이름으로 전달한다.

## Ch10 — 기한 / 4월

- 중심 갈등: 마감 앞에서 누구의 위험부터 줄일 것인가. A 공적 보호 / B 경기와 경계 / C 통로 폐쇄 / D 물자 차단 / E 캐비닛 완성.
- 공통: 경계 강화·F-09 작동 변화. 나르시사 위험·임무는 확인된 증언/문서로 단계적으로 안다. 학교 안전 경로에도 필요한 새 증거 획득 기회를 둔다.
- 주요 장면, 부엌 옆 복도: 헤르미온느가 명단을 접었다. “한 명을 숨기는 건 할 수 있어. 그 한 명이 다른 사람을 데려오는 건 다른 계획이야.”
- 선택과 대가: 실현 가능한 대안/가담 거절과 대피 지원/위험한 거래. 보호가 성공해도 애정과 연애 상태를 보상하지 않는다.
- 이월·회수: 보호·대피·차단 준비, 피해 회복 행동→Ch12 권한·Ch13 결과. 드레이코는 명령을 수행할지 자기 결정을 내린다.

## Ch11 — 각자의 방식 / 5월 초

- 중심 갈등: 비밀 공유가 연대인가 부담 전가인가. A 검증회 / B 대피 역할 / C 지도 복사 / D 증인 보호 / E 목표 확인.
- 공통: 학생들은 자기 근거로 위험을 감지한다. KN_TARGET은 E 또는 정식 보호 브리핑에서 확인한다. 신체 변화는 별도의 공개 동의 없이 말하지 않는다.
- 주요 장면, 휴게실: 론이 의자를 빼 주었다. “같이 가자는 말 전에, 어디까지 가는 건지부터.” 나는 앉지 않고 지도를 폈다.
- 선택과 대가: 필요한 정보만 동의받아 전달/전부 공개/혼자 감당. 높은 호감이어도 동료는 일을 거절할 수 있고, 낮아도 역할이 분명하면 협력한다.
- 이월·회수: 누가 무엇을 알고 어느 역할에 동의했는지→Ch12 명령권·Ch13 배치·Ch14 관계. F-13은 실제 발언을 들었을 때만 설치한다.

## Ch12 — 갈림길 / 5월 말

- 중심 갈등: 옳은 목표가 당사자 동의를 대신할 수 있는가. A 신고 준비 / B 대피 연합 / C 차단 계획 / D 보호 협상 / E 개인 결정.
- 공통: 사건 준비 A~E와 최종 접근 R1~R6는 별개 축이다. 기존 K-19 의미·엔딩 ID를 보존한다. R6 무개입은 항상 가능하다.
- 주요 장면, 교장실 문턱: 말포이는 서류보다 펜을 오래 봤다. “이름을 쓰는 건 내가 해.” 나는 펜에서 손을 뗐다.
- 선택과 대가: 검증된 위험 증거 공개/자기 결정 지원/비밀로 강요/철수. R2의 임무 폭로를 신체 변화 폭로와 동일하게 취급하지 않는다.
- 이월·회수: 접근 R·동의한 역할·실제 준비·미해결 책임→Ch13. 판시·루나는 해리의 거절과 무관하게 자기 진술·지도 사용 범위를 정한다.

## Ch13 — 탑의 밤 / 6월

- 중심 갈등: 계획이 깨졌을 때 무엇을 포기할 것인가. A 증거 인계 / B 호송 / C 봉쇄 / D 보호 이동 / E 탑 대치. 같은 밤에 병행된다.
- 공통: 세계 결과를 공유하되 해리가 직접 플레이하는 일은 다르다. 탑에 없으면 비공개 대화를 전지적으로 보여 주지 않고 사후 확인 가능한 결과만 전달한다.
- 주요 장면, 계단: 뒤에서 이름을 불렀다. 위에서는 문이 부서졌다. 나는 들것의 손잡이를 다시 잡았다. “먼저 내려가. 난 이쪽을 들게.”
- 선택과 대가: 역할 유지/인계 후 이동/무단 이탈. 구조 성공·학교 피해·탑 결과·나르시사 상태를 분리한다. 사랑이 구조 준비를 대신하지 않는다.
- 회수: F-12/13·맹세·교장의 인지는 실제 정보 획득 시점에. 전투는 부상·선택·결과 중심이며 노골적인 묘사를 하지 않는다.

## Ch14 — 여름의 문턱 / 6월 말

- 중심 갈등: 끝난 사건의 책임은 누가 계속 지는가. A 진술·징계 / B 팀 재편 / C 지도·추모 / D 거처·증인 보호 / E 관계 재정의.
- 공통: 기존 OUT 네 축과 E-A1~F2 결과군을 일관되게 결산하고 인물별 성과·관계 코다를 독립 모듈로 붙인다. 이별해도 논문·선발 결과가 지워지지 않는다.
- 주요 장면, 플랫폼: 판시가 주소를 접었다. “답장을 달라는 뜻은 아니야.” 나는 받기 전에 물었다. “보내도 되는 주소야?” 그녀가 고개를 끄덕였다.
- 선택과 대가: 실제 보상·정정 실행/다시 시작 제안/친구/거리 두기. 상대의 대답이 따로 있으며 구조 성공이나 높은 호감이 재결합을 보장하지 않는다.
- 회수: Ch1 약속·Ch3 책임·Ch5 부상·Ch7 공저·Ch9 시험·Ch11 공개 범위. 친밀 코다는 동의한 손잡기·입맞춤·암전 여운까지만 쓴다.

## 구현 충돌·다음 우선순위

1. Ch2 E 독립 경로는 현재 없고 드레이코 선호가 D로 간다. E 훅·시료 사건을 추가하되 기존 D와 일반 도입·이력을 보존해야 한다.

3. Ch3~8 기존 공통 원고를 각 사건의 일부로 재사용하되 미선택 경로의 KN·수첩·도감 공개를 새로 분리해야 한다. 검증 없는 전체 재작성은 금지한다.

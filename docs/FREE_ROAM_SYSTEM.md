# FREE_ROAM_SYSTEM — 자유 일과(공간·시간 기반 탐색) 설계와 구현

> 기준 코드: `src/data/places.ts`(규칙) · `src/data/mapLayout.ts`(좌표·도형) · `src/engine/core.ts`(시간 진행) · `src/ui/MapView.tsx`(지도 UI). 이전 설계 메모는 [MAP_UI_PLAN.md](MAP_UI_PLAN.md).

## 1. 변경 요약
- **이전**: 장소 카드 그리드 → 모든 장소에서 같은 5개 활동 → 활동 1회 = 시간대 1칸(구간마다 6~9번 클릭).
- **이후**: 지도 마커 → 장소 패널의 장소별 활동 → 활동마다 소요 시간(1~6칸). 구간 전체 시간은 그대로(2~3일 × 3칸).
- 시간 단위는 "시간대 칸"(오후1 / 오후2 / 저녁). 진행 커서는 `dayIdx*3+slotIdx` 하나라 **구버전 저장(고정 슬롯 방식)이 그대로 이어진다**. 저장 구조 변경은 선택 필드 `routine.at`(지도의 현재 위치) 하나뿐이다.

## 2. 규칙
- 장소 출입 조건(시간대·요일)과 활동의 시간대 제한은 `PLACE_RULES`에만 있다. UI는 `listActions`/`placeInfo`(core.ts)가 돌려주는 사유를 그대로 표시한다.
- 활동은 **시작 시간대**에 열려 있어야 하고, 문을 닫는 시간대를 지나야 하는 활동은 할 수 없다(`overnight` 표시가 있는 활동 제외 — 밤새 끓이는 약).
- 남은 시간(`remainingSlots`)을 넘는 활동은 실행되지 않는다(상태 불변). 남은 시간은 음수가 되지 않는다.
- 일과가 끝나면 한 곳(`pickActivity`/`skipRoutine`의 `finishRoutine`)에서 `routine.then`으로 넘어간다. "남은 시간 넘기기"는 확인 단계를 거쳐 즉시 다음 스토리로 간다.
- 만남: 활동이 차지한 칸들 중 한 칸이라도 드레이코 일정표(GAME_BIBLE 3.2)와 장소가 맞으면 그 장소의 만남을 소비한다. 맞지 않으면 조연 일상(friends)이 나온다. 필수 스토리 이벤트는 일과 밖(`then`)에 있어 시간 경과로 누락되지 않는다.
- 보상 비공개: 결과는 서술로만 알린다(수치·능력치 이름 없음). 소요 시간과 끝나는 때는 보여 준다.

## 3. 장소·활동·소요 시간·제약
| 장소(구역·환경) | 출입 조건 | 활동(소요) |
|---|---|---|
| 대연회장(성·실내) | 상시 | 식사·식탁 대화·소문 듣기(짧게, 오후1·저녁만) / 빈 홀에서 쉬기(짧게, 오후2만) |
| 도서관(성·실내) | 저녁 닫힘 | 공부(짧게) / 자료 조사·집중 공부(오후 내내) |
| 마법약 교실(성·실내) | 저녁 닫힘, 주말 닫힘(감독 교수 없음) | 교재 복습(짧게) / 마법약 실습(오후 내내) / 배합 연구(하루, 밤새 이어짐) |
| 기숙사 휴게실(성·실내) | 상시(해리의 기숙사) | 마법사 체스·쉬기·숙제·친구와 대화(짧게) |
| 4층 빈 교실(성·실내) | 상시(챕터별 개방) | 주문 연습(짧게) / 집중 수련(하루) / 이틀 수련(이틀) |
| 안뜰(부지·실외) | 저녁 닫힘(통금) | 산책·주문 연습·가벼운 대화·벤치에서 쉬기(짧게) |
| 퀴디치 경기장(부지·실외) | 저녁 닫힘(후치 교수 규칙) | 빗자루 비행·퀴디치 연습·연습 구경(짧게) / 집중 훈련(오후 내내) |
| 호수(부지·실외) | 저녁 닫힘(통금) | 호수 바라보기·물가에 앉기(짧게) |
| 온실(부지·출입 허가) | 화·목 오후만(스프라우트 허가) | 약초 손질(오후 내내) |
- 빗자루 비행·퀴디치는 실외 장소에만 있다(테스트로 보장). 저녁 시간대에 열린 곳은 대연회장·휴게실·4층 교실뿐이다.
- 지도 구역: 성 내부(층별 개념도: 탑·4층·도서관 층·1층·지하) / 성 밖 부지(개념도). 실제 지리를 가장하지 않으며 좌표는 `MARKERS`에서 교체할 수 있다.

## 4. 균형 원칙(테스트: freeroam.test.tsx)
- 한 능력치의 시간당 성장 ≤ 2.5, 전체 ≤ 3. 긴 활동은 한 가지에 집중하는 대신 다른 성장을 포기하고(집중 공부는 지성 +5뿐), 같은 시간에 여러 곳을 돌며 사람을 만날 기회를 잃는다.
- 특화 정책은 해당 능력치를 균형형보다 뚜렷이 높이지만 다른 능력치는 낮다. 일과 클릭 수는 정책에 따라 35~75회(이전 고정 75회).
- 분포 변화와 임계값 영향: [BALANCE_REPORT.md](BALANCE_REPORT.md) 9장.

## 5. 일상 랜덤 이벤트
활동 뒤 장소·활동·시간대·챕터 조건에 맞는 작은 사건을 추첨한다(평범한 결과가 기본). 규칙·분포·작성법: [RANDOM_EVENTS.md](RANDOM_EVENTS.md).

## 6. 확장 지침
- 새 장소: `LOCATIONS`(이름·설명) + `PLACE_RULES`(구역·환경·출입·활동) + `MARKERS`(좌표) + 챕터 일과 노드의 `locations`.
- 새 활동: `ACTIVITY_DEFS`(소요·성장) + 장소 `acts`. 장소 이름에 맞는 서술은 `constants.ts`의 `LOC_FLAVOR`/`ACT_CLOSE`.
- 챕터마다 다른 개방 장소는 일과 노드의 `locations`로 지정한다(예: 챕터 2 폭발 이후 4층 교실 제외).

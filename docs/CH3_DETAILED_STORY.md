| 요일 | 장면 | 핵심 |
|---|---|---|
| 월 | `v2c3_wC*` [프로토] | 매듭/분필 → 숨어서 지켜봄(루나 등장) / 위치 기억 / 지움 |
| 화 호숫가 | `ev3_c_count` [설계] | 루나가 "열세 번째"를 셀 계획을 말한다. 해리는 (a) 같이 세기 (b) 위험을 알려 말리기(비밀을 말하지 않고) (c) 아무 말도 안 함 |
| 수 | 필치 순찰표 N-08 [설계] | 순찰 간격의 빈틈을 알게 됨 → Ch13 시간 계산의 복선 |

- 후폭풍: 어떤 선택이든 루나는 멈추지 않는다 — 해리가 어떻게 **곁에 서는가**만 바뀐다.

### D. 슬리데린 — 「마감 이후」 (중간 상세)
- 월 `v2c3_wD*` [프로토]: 이름 없는 봉투 → 수요일 안뜰.
- 수 `ev3_d_courtyard` [설계]: 판시는 마감일(9/30)에 **자기 손으로 드레이코 대신 답장을 썼다**고 고백한다. 해리의 선택: (a) 같이 거짓 답장을 고친다(공범: 드레이코의 자율성을 침해, 판시 신뢰↑) (b) 드레이코에게 말해야 한다고 설득한다(판시와 정면, 약속 위반 아님 — 판시가 아닌 본인 몫) (c) 모른 척한다.
- 토 K-07 변형: 나르시사의 편지가 **답장에 대한 답**임을 드러내는 한 줄(해리는 읽지 못하고 드레이코의 반응으로만 추측: 얼굴이 하얘지는 이유가 둘로 갈림).
- 폭로 이력이면 판시는 해리가 아닌 다른 이에게 부탁한다(`FLAG_P3_D_AVOIDED`) → 판시 독립 서사가 해리 없이 진행됨.

### E. 불안정한 마법 — 「보랏빛」 (중간 상세)
- 월 `v2c3_wE*` [프로토]. 화 방과 후: 론과 빈 교실에서 안전하게 재 보기(스니코스코프). 목: 지팡이 오작동의 "프로테고 잔향"(방패를 펼치면 가장자리가 지워짐) 확인. 금 S-03에서 스네이프는 `FLAG_P2_SNAPE_WATCHING`이면 질문이 두 번째 문장부터 해리의 지팡이를 향한다. 일요일: 론이 먼저 묻지 않고 곁에 앉아 있다.
- 핵심 원칙: 불안정은 해리의 **책임감**의 문제다. 치료·원상복구의 방법을 찾는 사건이 아니다.

## 5. 관계 상태별 변형 (모든 경로 공통 규칙)
| 상태 | 변형 |
|---|---|
| `FLAG_*_OPEN` (명시적 동의 있었던 관계) | 일요일 말투가 한 단계 가깝다. 대신 약속을 어기면 갈등이 더 크다(지니·판시 갈등 장면 변형) |
| `FLAG_PAN_NIGHT` | 수요일 안뜰의 판시는 체면과 부끄러움 사이: 소문 단속 요구, 질투/보호 반응(`REACT` 근거가 있을 때만) |
| `*_DISTANT`/`*_DECLINED_GENTLY` | 선택 후에도 우정이 이어진다. 거절은 처벌되지 않지만 말투에 거리가 남는다 |
| 질투(jealousy) | 단계 3 + 연애 열림이 필요 → 챕터 5 이후. 챕터 3은 경쟁심·서운함·호기심까지 |
- 드레이코는 연애 대상이 아니라 **주연 조연**: 징계 시간의 대사는 해리의 행동(허락을 구함/말함/지킴)에 따라 신뢰·자율성이 변한다.

- **[프로토]**: `v2c3_route`(주 사건 판정) · `v2c3_wA~wE`·`wG`와 선택 결과 장면(W-01~W-05) · `v2c3_join`(종단 END). 기존 챕터 3과 **연결되어 있지 않다.**
- **연결 방법(승인 후)**: `ch3_open`의 제목·월요일 도입 뒤에 `go('v2c3_route')`, `v2c3_join`의 `END`를 `go('ch3_detention')`으로 교체하고 `ch3_open` 후반(트로피 진열실~`iff FLAG_DAWN_VIGIL`)을 `ch3_detention`으로 분리. 기존 `ch3_*` 도달성 감사와 EH-01 신뢰 분포 재측정 필요.
- **미구현**: 화~목 경로 행사(`ev3_*`/`ap3_*` 캘린더), 금·토·일 변형 줄, 플래그 `FLAG_P2_LIED_TO_HER`·`FLAG_P2_UNSTABLE`·`FLAG_P2_HER_KNOWS_SOMETHING`(챕터 2 초안 장면과 함께 구현).

## D. 슬리데린 내부의 거래·비밀·갈등
1. **도입 [구현]**: 월요일 저녁 지하 복도, 판시의 부탁(Q-04). 
2. **조사·탐색**: 금요일 도서관(Q-08)에서 편지 이야기·마감. **[초안]** 연락책 목격 `ch2_d_courier`: 4학년 슬리데린이 판시에게 봉인된 봉투를 건네고, 판시가 "마감 전엔 답 없어"라고 한다.
3. **이해 충돌**: 판시(보호·체면) / 말포이(자율) / 연락책(자기 가문 눈치) / 헤르미온느(도서관 목격자) / 해리(약속).
4. **관계 변형 [구현]**: 판시의 갈등(관여 안 함/폭로)·친밀(한 뼘 앞·밤). 폭로 선택은 `KN_PANSY_NIGHTS`가 있을 때 정상 플레이로 도달.
5. **선택과 후폭풍**: Q-04(지켜봄/직접 주선/관여 안 함), Q-08, L-14 D(폭로 → 공손한 거리 두기, 말포이의 경계↑). **[초안] Q-14 연락책 앞에서**: 가로막는다(판시와 정면 충돌, 연락책의 소문) / 따라간다(봉투의 인장 확인 `KN_COURIER_SEAL`, 위험) / 지켜만 본다(약속 유지).

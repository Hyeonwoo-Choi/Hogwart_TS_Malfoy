# V2_RELATIONSHIP_ROUTES — 관계 단계 · 조건부 루트 · 질투/반응 규칙

> 상위: [V2_BRANCHING_STORY.md](V2_BRANCHING_STORY.md). 반응 훅의 원리는 [V2_HEROINES.md](V2_HEROINES.md) 3장. 구현: `data/v2c2r.ts`(조건표·장면), `engine/reactions.ts`(반응표), `engine/cond.ts`(`REACT_`·`SAW_`·`stage.`·`romance.`). 숨은 수치와 정확한 조건식은 UI에 공개하지 않는다.

## 1. 관계 단계 (7단계 모델 ↔ 엔진 상태) [구현: 0~3 + 연애 상태]
| 모델 | 엔진 표현 | 비고 |
|---|---|---|
| 1 관심·경계 | stage 0 | 초기 |
| 2 개인적 호기심 | stage 1 | 만남 이벤트·약속 |
| 3 사적 대화·비밀 공유 | stage 2 | 경로 행사 고유 고백(`FLAG_P2_*_CONFIDED`) |
| 4 상호 호감·밀당 | stage 3 | 친밀 장면 진입 |
| 5 감정의 확인 | `romance:X=open` | 명시적 합의가 담긴 선택에서만 |
| 6 명시적 관계 합의 | `romance:X=together` | **챕터 2에서는 효과 없음**(테스트로 금지) |
| 7 더 깊은 친밀·장기 갈등 | 미구현 | 후속 챕터 설계 |
- 신체 접촉은 호감도만으로 일어나지 않는다. 키스·손잡기 장면은 장면 안에서 상대가 말로 허락하는 선택(예: "손을 잡아도 돼?", "확인해 봐도 돼?", "가도 돼?")에서만 일어난다. 거절·보류 선택은 신뢰·호감 하락이나 경계 상승이 없다(테스트).

## 2. 조건부 루트 유형 [구현 여부 표기]
| 유형 | 의미 | 챕터 2 구현 |
|---|---|---|
| A 일반 | 관계 조건 없이 진행 | [구현] `ch2_eve_gen`. 어떤 조건에도 해당하지 않으면 항상 도달 |
| B 친밀 | 신뢰·단계·**함께한 사건**이 모두 충족 | [구현] 5개 `ch2_eve_i_*` |
| C 갈등 | 약속 어김·규칙 위반·관계 악화 | [구현] 5개 `ch2_eve_t_*`(갈등 + 반응 겸용) |
| D 질투/반응 | 목격·전언 근거 + 단계·성격 | [구현: 경쟁심·서운함·호기심] / 질투(jealousy)는 단계 3 + 연애 상태 필요 → **챕터 2에서 정상 플레이로는 거의 도달 불가**(코드는 있고 단위 테스트에서 단계를 직접 맞춰 검증) |
| E 비밀 공유 | 함께한 사건 + 신뢰 → 이 경로에서만 얻는 정보 | [구현] 경로 행사 속 고유 고백 4종(Q-05~Q-08) |
| F 특별 관계 | 여러 챕터에 걸친 일관된 행동 | [설계] 챕터 7~8 |

## 3. 조건표 (챕터 2, 금요일 저녁 `ch2_eve`)
| 인물 | 친밀(B) | 갈등·반응(C/D) |
|---|---|---|
| 헤르미온느 | stage≥2, 신뢰≥54, (룬 약속 성공 / 온실 행사 / 연구 행사 / 균열 동행) | 규칙 위반(`FLAG_P2_BREACH`) 또는 판시와의 만남을 목격(`REACT_hermione_pansy`) |
| 지니 | stage≥2, 신뢰≥44, (경기장 약속/행사/마지막 연습) | 후치 보고(`FLAG_P2_HOOCH_CHECK`) 또는 루나와의 만남 목격 |
| 루나 | stage≥2, 신뢰≥43, (호숫가 약속/온실 행사/낮의 계단) | 계단 위치를 알림(`FLAG_P2_STAIR_SEALED`) |
| 판시 | stage≥2, 신뢰≥8, (안뜰 약속/경기장 행사/편지 이야기/약속 지킴) | 관여 안 함(`FLAG_P2_STAYED_OUT`) 또는 헤르미온느·지니와의 만남 목격 |
| 말포이 | 신뢰≥7, 존경≥22, (마법약 교실 계획 성공 / 직접 물어봄) | 직접 대화 주선(`FLAG_P2_TALK_DRACO`) |
- 임계값은 수치 척도가 인물마다 다르기 때문에 다르다(측정: 헤르미온느 초기 신뢰 ≈50, 지니·루나 ≈40, 판시 0~11, 말포이 0~9). 숫자만으로 열리지 않는다: 신뢰 99·단계 3이어도 함께한 사건이 없으면 일반 장면(테스트).
- **우선순위**: 말포이를 고른 경우 말포이 → 사건 경로의 히로인(갈등 먼저, 그다음 친밀) → 다른 인물의 갈등·반응 → 다른 인물의 친밀 → 일반. 한 번에 한 장면만 재생된다.
- 특별 장면을 놓쳐도 메인 스토리는 같다. 호감이 낮은 플레이어도 일반 장면 → 첫 경기로 이어진다.

## 4. 질투·반응 규칙 [구현: `engine/reactions.ts`, 조건 `REACT_<관찰자>_<대상>`]
1. **목격**: 관찰자가 해리와 대상의 만남을 직접 보았는가(`meet:<대상>@<증인>` 효과의 증인은 일정표상 같은 장소·시간에 있던 사람만).
2. **기간**: 최근 3일 이내.
3. **단계·연애 상태**: 단계 0은 모두 무관심. 단계가 올라가야 이유가 생긴다.
4. **성격**: 반응표(관찰자 × 단계 × 연애 열림).
| 관찰자 | 평상 단계 0/1/2/3 | 연애가 열린 경우 |
|---|---|---|
| 헤르미온느 | 무관심 / 호기심 / 서운함 / 호기심 | …/ 단계 3 **질투** |
| 지니 | 무관심 / 무관심 / 경쟁심 / 경쟁심 | …/ 단계 3 서운함 |
| 루나 | 무관심 / 호기심 / 호기심 / 호기심 | …/ 단계 3 서운함 |
| 판시 | 무관심 / 경쟁심 / 경쟁심 / 경쟁심 | …/ 단계 3 **질투** |
- 단순히 다른 히로인과 대화했다는 이유로는 반응하지 않는다(목격 없음 · 오래전 목격 · 증인이 다른 사람인 경우 모두 반응 없음 — 테스트).
- 챕터 2의 목격 근거: 연구 행사(판시가 도서관에 있음) / 퀴디치 행사(판시가 관중석) / 호숫가 행사(지니가 둔덕) / 슬리데린 행사(헤르미온느가 도서관) — 모두 일정표에 맞는 자리다.
- 반응이 높아져도 로맨스를 자동 발생시키지 않는다. 장면의 선택(사실 설명 / 신경 쓰였는지 묻기 / 넘기기 등)에 따라 회복·재정립·거리 두기로 이어진다.

## 5. 복수 관계 [구현 범위: 제한]
- 챕터 2에서는 연애 상태 `open`까지만 있으며 `poly:`·`together` 효과는 없다(테스트). 여러 히로인과 친밀감을 쌓는 플레이(multi)는 서로 다른 히로인의 친밀 장면에 도달하지만 다자 연애는 성립하지 않는다.
- 독점을 원하는 인물의 거부, 합의 모델은 [V2_DESIGN.md](V2_DESIGN.md) 5장 설계를 따르며 이번에 구현하지 않았다.

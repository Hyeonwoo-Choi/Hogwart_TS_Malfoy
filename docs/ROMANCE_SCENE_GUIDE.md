# ROMANCE_SCENE_GUIDE — 친밀한 장면·특별 장면 연출

## 1. 원칙
- 특별 장면은 보상이 아니라 **캐릭터 이해 또는 관계 변화**를 만드는 사건이다. 존재 이유를 한 줄로 쓸 수 없으면 넣지 않는다.
- 수치가 높다고 자동 발생하지 않는다. 조건 = 관계 단계 + 현재 갈등 + 신뢰·호감·끌림 + **자율성·자기수용** + 과거 선택 + 장소·상황 + 두 사람의 명확한 의사.
- 드레이코는 특별 장면에서도 자기 의사를 표현한다: 동의, 거절, 망설임, 거리 설정("거기까지"), 주도권. 해리는 그 경계를 넘지 않는다.
- 관계가 나쁜 경로에는 로맨스를 억지로 넣지 않는다. 대신 비로맨스 특별 장면(라이벌의 인정, 뜻밖의 협력, 약점을 알게 되는 순간, 오해의 일부 해소, 각자의 길)을 둔다.
- 자기수용과 애정은 별개다. 해리에게 마음을 여는 것이 변화를 받아들이는 것을 뜻하지 않으며, 그 반대도 아니다.
- 성인 AU(전원 만 18세 이상). 과하지 않은 수준에서 어느정도 부분 노출은 허용한다.

## 2. 단계
| 단계 | 내용 | 표현 수단 |
|---|---|---|
| R1 정서적 친밀감 | 시선 교환, 조용한 동행, 함께 앉아 있는 시간, 사적인 대화, 손을 맞잡음 | 침묵, 같은 방향을 보는 구도, 거리 유지 |
| R2 로맨틱한 긴장 | 거리감의 변화, 얼굴 붉힘, 긴 침묵, 시선을 의식함, 예상 못 한 배려, 둘만의 비밀스러운 순간 | 시선이 마주쳤다 먼저 피함, 숨 |
| R3 성숙한 로맨스 | 상호 동의에 기반한 키스, 명확한 감정 표현, 관계의 전환점 | 짧은 묘사, 컷 전환 |
| R4 사적 친밀감의 암시 | 비공개 공간, 관계의 변화, 장면 전환과 여운 | 암전·다음 날 대사에 반영된 친밀감 |
| RIVAL | 비로맨스 특별 장면 | 정면 구도, 대등한 거리 |

## 4. 향후 단계 기준(설계 가이드, 수치는 해당 회차에서 확정)
- R1: 언제든(사건이 정당화하면).
- R2: 신뢰 ≥ 25 ∧ 끌림 ≥ 10 ∧ 자율성 ≥ 40(간섭으로 자율성이 깎인 상태에서는 긴장 대신 반발).
- R3 키스: 관계 상태가 BOND 경로 ∧ 미해결 배신 없음 ∧ 장면 안의 명시적 동의(대사로).
- R4: R3 이후, 해당 장면의 맥락이 사적 공간·합의를 명확히 할 때만. 암전으로 처리.
- 모든 단계: 조건 충족/비충족 경로를 테스트한다(`ch2.test.ts`의 "특별 장면" 블록이 예시).

## V2 개정: R1~R4 진행 제한 재검토 (2026-10-22)
- 기존 R2(신뢰≥25·끌림≥10·자율성≥40)·R3(BOND 경로) 같은 **말포이 전용 수치 문턱**은 다중 히로인 구조에서 그대로 쓰지 않는다. V2에서는 인물별 신뢰·단계에 **함께 겪은 사건**(약속 성공·행사·비밀 공유)을 함께 요구한다([V2_RELATIONSHIP_ROUTES.md](V2_RELATIONSHIP_ROUTES.md)).
- 허용 범위: R3 키스·손잡기는 말로 하는 허락이 있는 선택에서만. R4(사적 친밀의 암시)는 **비밀을 나눈 뒤 높은 신뢰 + 선택으로 의사 확인(멈추자고 하면 멈춘다)**이 있을 때 장면 전환(`trans`)으로 처리하고, 전후의 감정·비밀·소문·거리감을 서사에 반영한다. 직접 묘사는 쓰지 않는다. 구현: 판시의 밤(`ch2_eve_i_pansy_night*`).
- 거절·보류는 신뢰·호감 하락 없이 존중된다. 원치 않는 접근 강행을 성공으로 그리지 않는다.
- 과감한 비폭력·폭력 선택(멱살·폭로·약속 배신)도 허용하되 반드시 후폭풍(징계·소문·관계 변화)을 둔다. 단, 생각지도 못한 변수를 위해 때렸더니 오히려 묘한 흥미를 느끼는 경우도 있다.

## 1. 문제 진단 (이번 개편의 출발점)
- 챕터 2~8의 메인 선택 15개(K-05~S-04)는 모두 말포이를 향한다. 챕터 1의 다섯 경로는 챕터 2에서 모두 같은 장면(스네이프 징계 / 판시의 추궁)으로 합류했고 경로 결과는 챕터 2에 쓰이지 않았다.
- 개편 후: 경로는 **챕터 1에서 결정 → 챕터 2의 시작 사건·행사·밤의 접근 방식·마무리를 바꾸고 → 챕터 3 이후로 플래그가 이월**된다. 말포이 변화 사건(챕터 2 말미)의 인과는 모든 경로에서 같다.

## 2. 사건 경로 (이야기 경로 ≠ 연애 경로) [구현]
사건 경로는 `FLAG_P2_*`(연구·퀴디치·성의 비밀·슬리데린), 연애 관계는 `bonds`(단계·연애 상태)와 감정 수치로 **따로** 관리한다. 연구 경로를 골랐다고 헤르미온느와의 연애가 강제되지 않으며, 관계 장면은 어느 경로에서든 다른 히로인에게 열릴 수 있다.
| 경로 | 결정 | 월요일 시작 사건(선택) | 경로 행사 | 밤 7층 | 챕터 끝 후속 |
|---|---|---|---|---|---|
| A 연구 | H-08 헤르미온느 / `OB_RUNE_WALL` / 온실 행사 성공 | 제한 구역 책(Q-01): 서명 요청 / 몰래 열람 / 교수에게 보고 | 금 오후2 도서관(Q-05) | 책의 문장(충돌 위험)이 떠오른다 | 월요일 도서관, 사본의 매듭과 문의 비교 |
| B 퀴디치 | H-08 지니 / `OB_PITCH_FLASH` / 경기장 행사 성공 | 경기장 사고(Q-02): 현장 조사 / 후치에게 보고 / 지니에게 맡김 | 목 오후2 경기장(Q-06) | 이십 분 간격 숫자가 이어진다 | 창 번쩍임 간격이 깨진 것 |
| C 성의 비밀 | H-08 루나 / `FLAG_LUNA_COUNT7` / 호숫가 행사 성공 | 태피스트리 뒤 계단(Q-03): 같이 오름 / 표시만 / 필치에게 알림 | 금 오후2 호숫가(Q-07) | 숨은 나선 계단으로 소리 없이 7층에 도착(봉쇄하면 큰길) | 열세 번째 소리를 못 센 것 |
| D 슬리데린 | H-08 판시·말포이 / `KN_PANSY_NIGHTS` / 안뜰 행사 성공 | 가문의 편지(Q-04): 지켜봄 / 직접 대화 주선 / 관여 안 함 | 금 오후2 도서관(Q-08) | 판시의 말(토요일 밤)이 떠오른다 | 가문 마감(이번 달 말) |
| 일반 | 위 조건 없음 | 기존 시작(스네이프 징계 / 판시의 추궁) | 없음 | 기존 | 기존 |
- 판정 순서(`ch2_route`): 명시적 선택(H-08) → 챕터 1에서 얻은 단서 → 행사 결과 → 일반. 말포이 약속(H-08 E)은 D 경로로 합류하며 말포이 우선 장면을 가진다.
- 놓쳐도 진행: 경로 행사를 놓쳐도 기본 단서(`KN_KNOT_BLOCK` 등)는 시작 사건에서 이미 주어진다. 행사는 신뢰·단계가 충분할 때만 **고유 정보**(가설·목격·고백)를 추가로 연다.
- 공통 메인(그대로): 만찬(K-05) · 4층 폭발 · 첫 경기(K-06) · 7층 사고 → 변화(S-01) → 환영(S-02).

## 3. 경로 선택이 공통 사건에 미치는 영향 [구현]
| 경로 결과 | 영향 장면 |
|---|---|
| 허가서 요청(A) | 만찬에서 헤르미온느가 슬러그혼에게 서명을 받는다(`FLAG_P2_PERMIT_OK`) → 금요일 책 열람 |
| 루나 경로 | 만찬에서 루나가 말포이에게 서쪽 탑 창을 묻는다(말포이의 반 박자 늦은 대답) |
| 판시 경로 | 만찬에서 말포이의 로브 안 봉인된 편지가 보인다 |
| 지니 경로 | 첫 경기의 지니 대사가 점검·삐짐·시간 확인에 따라 달라진다 |
| 계단 지식 | 7층에 가는 방법이 달라진다(`OB_HIDDEN_STAIR` && 봉쇄 안 함) |
| 모든 경로 | 밤 도입 문장과 챕터 끝 후속이 다르고, 사건 수첩 `seventh-door`에 경로별 단서가 쌓인다 |

## 4. 챕터 간 상태 전달 [구현: 챕터 1 → 2 → 3 시작 / 설계: 이후]
- 이월 상태: `FLAG_P2_*`(경로·선택 결과), `KN_*/OB_*`(단서), `bonds`(단계·연애 상태), 감정 수치, 약속(`promise`), 관계 장면 결과(`FLAG_HER_OPEN` 등), 용어 읽음.
- 챕터 3 이후 소비: **설계만**. 다음 챕터가 참조할 예: `KN_PAIR_HYPOTHESIS`(문이 쌍일 수 있다), `KN_DOOR_DIRECTION`, `KN_LETTER_DEADLINE`, `KN_GINNY_SAW_SHADOW`, `FLAG_P2_BREACH`(규칙 위반 이력).

## 5. 후속 챕터 분기 설계 [설계 — 미구현]
우선순위(영향·재사용 순): ① 챕터 3(편지·편입)에 경로별 도입 1장면 + 마감(가문 편지) 반영 ② 챕터 4(퀴디치 경기 후속)에 지니 경로 결과 ③ 챕터 5~6(와드·표식)에 연구 경로의 쌍 가설 ④ 챕터 7~8에 관계 단계 3 이상의 특별 관계 루트(F). 챕터마다 공통 메인 1 + 사건 분기 ≥2 + 관계 조건부 장면 1 + 경로 행사를 둔다. 상세 목표: 헤르미온느(문의 구조·규칙과 정직), 지니(경기와 자기 결정), 루나(숨은 공간의 지도), 판시(기숙사 내부 정치와 약속의 무게), 말포이(기존 서사).

## 6. 블라인드 사건 선택(H-08 개정) [구현]
- **변경**: 챕터 1의 H-08은 더 이상 "누구와 어떤 약속을 할지" 메뉴가 아니다. 해리가 한 주 동안 귀와 눈에 걸린 **정체불명의 일**(접힌 양피지·경기장의 둔탁한 소리·호수 쪽 숫자 소리·벤치 아래 쪽지·지하 교실의 불빛·아무것도 따라가지 않음) 중 무엇을 따라갈지 고른다. 선택 ID(H-08)·키(A~F)·플래그(`FLAG_RT_*`)는 저장·테스트 호환을 위해 유지했고, **표시 문구·게시판 문구만** 바뀌었다.
- 이름은 만나는 장면(`ev1_ap_*`·`ev1_pl_draco`)에서 처음 드러난다. 만나기 전 게시판·메모·밤 도입에는 인물 이름이 없다(만나지 못한 경우 익명 도입).
### 인수 기준 (모두 `blind.test.ts`로 자동 검증)
| # | 기준 |
|---|---|
| B1 | 선택지 장면의 어떤 문장에도 인물 이름·루트·호감·신뢰·보상·"약속"·"경로" 같은 메타 정보가 없다 |
| B2 | 선택지는 사건 단서(소리·물건·불빛·숫자)와 행동 동사(펼쳐 본다·확인하러 나간다·따라간다·주워 둔다·들여다본다)로 구성된다 |
| B3 | 선택 직후 해리의 메모에는 시간·장소만 있고 누구인지는 없다 |
| B4 | 챕터 1 개인 일정(`ap_*`·`pl_draco`)의 게시판 제목·공지에 이름이 없다(만남 전) |
| B5 | 이름이 나오는 밤 도입 문장은 그 인물과 실제로 만난 경우(`EV_ap_*`)에만 나오고, 못 만났으면 익명 도입이 나온다 |
| B6 | 각 약속 장면은 이전 경험(`FLAG_HR1_*`·`OB_SLEEVE`)에 반응하는 도입 줄을 가진다 — 같은 행동이 이전 이력에 따라 다른 느낌으로 이어진다 |
| B7 | 여섯 선택은 서로 다른 내부 경로를 가리키며 그 정보는 UI에 노출되지 않는다 |
- **미충족/한계**: 소리·장소로 상대를 짐작하는 정도의 공정성은 글쓰기 판단이다(경기장→지니, 지하 교실→말포이는 거의 확정 추리 가능). 정체를 더 모호하게 하려면 장소 단서도 일부 겹치게(예: 경기장 소리가 지니일 수도 판시일 수도 있게) 다듬어야 한다 → 후속. 선택에 따라 **인물이 바뀌는** 재배정(같은 행동이 다른 사람의 사건으로 이어짐)은 미구현이다(무작위 인물 배정 금지 원칙을 지키려면 이전 단서 기반 규칙이 필요하며 설계만 있다).

## 7. 챕터 1 → 챕터 2 분기 행렬 [구현]

|---|---|---|---|---|---|
| 양피지를 펼쳤다(A) 또는 룬 단서·온실 행사 성공 | 연구(`ch2_p_research`, Q-01) | 도서관(Q-05) | 책의 문장(충돌 위험) | 사본과 문의 비교 | 헤르미온느 |
| 경기장 소리를 확인했다(B) 또는 번쩍임 단서·경기장 행사 성공 | 퀴디치(`ch2_p_pitch`, Q-02) | 경기장(Q-06) | 이십 분 간격 | 간격이 깨짐 | 지니 |
| 숫자 소리를 따라갔다(C) 또는 일곱 번째 줄 단서·호숫가 행사 성공 | 성의 비밀(`ch2_p_secret`, Q-03) | 호숫가(Q-07) | 숨은 계단(봉쇄 시 큰길) | 열세 번째 소리 | 루나 |
| 쪽지를 주웠다(D) · 불빛을 들여다봤다(E) 또는 판시 단서·안뜰 행사 | 슬리데린(`ch2_p_sly`, Q-04) | 도서관(Q-08) | 판시의 말 | 가문 마감 | 판시(말포이 선택 시 말포이 우선) |
| 아무것도 따라가지 않았고 단서·행사 결과도 없다 | 일반(기존 시작) | 없음 | 기존 | 기존 | 관계 조건 충족한 인물 → 없으면 일반 |
- 사건 경로와 연애는 분리: 위 표의 "저녁(관계) 우선"은 그 경로 인물을 먼저 검사한다는 뜻일 뿐이며, 조건이 안 되면 다른 인물의 갈등·친밀 장면이 열린다.
- 과감한 선택의 후폭풍(챕터 2): 멱살(L-15 D) → 이십 점 감점·징계·소문·말포이의 존경 변화(`FLAG_P2_FIGHT_DRACO`, `FLAG_P2_DETENTION`), 비밀 폭로(L-14 D, 약속·단서가 있을 때만 선택지로 보임) → 판시의 신뢰 대폭 하락·정중한 거리 두기(`FLAG_P2_BETRAYED_PANSY`). 둘 다 공통 메인과 캐비닛 사고는 그대로 진행된다. 챕터 3 이후 소비는 설계만.

## 8. 이력 기반 후속 (H-08 B) [구현]
- 같은 행동("경기장 쪽의 둔탁한 소리를 확인하러 나간다")이 이전 이력에 따라 다른 사건으로 이어진다: **판시의 걱정을 진지하게 받아 주었고(H-01 A) 여름을 책·관찰로 보냈다면(P-01 A·B)** 소리의 주인은 관중석 난간을 걷어차는 판시이고, 후속 일정은 목요일 오후2 경기장(`ap_pansy_pitch`), 장면은 같은 선택(E-11)과 결과를 쓴다. 그 밖에는 지니(수요일 오후2). 무작위가 아니라 저장된 선택 이력 기반이며 같은 이력은 항상 같은 결과다.
- 기술: `v2c1_week_B`(조건 판정) → 지니 플래그를 되돌리고 `FLAG_RT_PANSY`+`FLAG_RT_PANSY_PITCH` 설정. 하류(밤 도입·챕터 2 경로·후속)는 `FLAG_RT_PANSY`를 그대로 쓴다.
- **한계**: 이 이력 분기는 B에만 있다. A·C·D·E의 정체는 여전히 단서 종류로 거의 짐작된다. 다음 후보: C(숫자 소리)를 루나 / 지니(경기 전 숫자 세기)로, E(지하 교실 불빛)를 말포이 / 판시로 갈라 단서를 겹치기.

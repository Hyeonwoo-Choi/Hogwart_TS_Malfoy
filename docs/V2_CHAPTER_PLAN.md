## 3. 엔딩 구조(성립 가능성 검토)
- **단일 루트**: 5인 각각(`romance=together` 하나, `partners=1`). 기존 메인 엔딩(E-xx 13종)의 "접근 방식"과 곱해 관계 코다만 바뀐다.
- **다자 루트**: `partners>=2` ∧ 모두 `poly=accepted` ∧ 기만 플래그 없음. 가능한 조합은 챕터 11의 동의 장면 결과로 정해지며 거절자는 우정 코다를 가진다.
- **비로맨스·라이벌**: 모든 `romance`가 none/declined/ended. 우정 코다 + 기존 라이벌 코다. 메인 엔딩은 동일하게 도달한다.
- 필요한 설계 확장(챕터 14 이행 시): 엔딩 ID는 DB의 13종 CHECK 제약을 바꾸지 않고 **관계 코다를 별도 상태로 저장**한다(엔딩 ID는 그대로).

## 4. 놓칠 수 있는 선택형 콘텐츠(분리)
- **필수(메인)**: K/S 선택과 장면. 히로인을 만나지 않아도 완주 가능.
- **선택(관계)**: `meets` 풀(자유 일과)·H 선택·챕터 사이 짧은 장면. 한 번의 플레이에서 모든 히로인을 만나기는 시간상 어렵게 설계한다(챕터 1의 일과 9칸 중 히로인 이벤트는 최대 4~5개).
- 한 번 놓친 이벤트는 다음 챕터의 풀에서 변형(대체 장면)으로 만회할 수 있다(단, 같은 마일스톤).

## 5. 다자 동의 장면 설계(챕터 11)
1) 해리가 "누구에게든 거짓말하지 않는다"를 선택(진행 조건) → 각 히로인과 따로 대화.
2) 각 장면은 해리의 제안이 아니라 **상대의 질문**으로 시작한다(`poly=asked`). 수락(`accepted`)·거절(`declined`)·보류.
3) 서로의 존재를 이미 아는 경우에만(만남 기록·증인) 질투·갈등 장면이 열린다. 모르는 사이의 당사자를 몰래 병행하는 선택지는 만들지 않는다.
4) 일부가 거절하면 그 사람과의 단일 관계(또는 우정)가 유효하게 이어진다.

| 후보 키 | 의미 |
|---|---|
| forward | 기본 카메라 방향 |
| at_target | 명시된 상대/관찰 지점 |
| sideways | 방향성 있는 측면 시선 |
| averted | 대화 대상에게서 시선 돌림 |
| down | 아래 방향 |
at_target에는 유효 target이 필요하다. 없으면 검증 오류, 해리로 추정 금지.
타깃 부재·퇴장·가림의 처리: 수요 경고 후 안전한 중립 대체 후보, 스토리 의미가 중요하면 승인된 대체 지시 필요.
좌우 반전은 시선·손잡이·의상 비대칭을 모두 바꿀 수 있다. 반전 허용 자산만 사용한다.
눈 레이어만 이동할 수 있는 범위와 머리 회전이 필요한 범위를 자산마다 명시한다.
캐릭터 A가 B를 보는 장면을 A가 해리를 보는 자산으로 무조건 대체하지 않는다.

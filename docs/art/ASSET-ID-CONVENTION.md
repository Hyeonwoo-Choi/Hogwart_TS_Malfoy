# Asset ID Convention
Status: DRAFT / NOT APPROVED
문서 제안이며 타입·JSON 스키마·Resolver·자동화 구현 승인이 아니다.

## 제안
- 내부 안정 ID: HERM_001 같은 예시는 설명용. 최종 접두사 표·대소문자·자릿수는 승인 대기.
- ID는 불변, 재사용 금지. 표정·외형·스포일러를 ID 문자열에 인코딩하지 않는다.
- 파일 이름은 a_000123.webp 같은 중립 이름 후보. 실제 인물·숨은 외형 키를 DOM 파일명에 노출하지 않는다.
- 파일 경로는 배포 위치, ID는 자산 정체성, revision은 파일 교체 이력으로 분리.
- 같은 정체성의 오류 수정은 ID 유지+revision 증가. 다른 포즈/표현 자산은 새 ID.
- deprecated ID는 alias/후속 ID와 이유를 남긴다. 삭제·무응답 변경 금지.
- 스토리에는 semantic request를 기록하고 HERM_002 같은 자산 ID 직접 의존을 기본 금지.

## 검증
전역 ID 유일성 / 대소문자만 다른 충돌 / OS별 경로 대소문자 / 파일 해시·revision / alias 순환 검사.
외형 비밀은 파일명 중립화만으로 보장되지 않는다. 정적 배포된 파일은 추측·열람될 수 있다.
강한 자산 접근 통제가 필요한지는 별도 보안·배포 설계 결정이다.

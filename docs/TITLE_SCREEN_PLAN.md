# TITLE_SCREEN_PLAN — 타이틀 화면 (설계 + 이번 회차 수정 사항)

## 이번 회차 수정(구현됨)
- 일반 플레이어 타이틀에서 개발용 정보("PHASE…", 에셋 개수) 제거 → `?qa`/`?debug=1`에서만 표시.
- "장면 갤러리" 버튼 추가(경험한 CG만 열람, 미경험은 ???).
- 부제 "갈라진 운명 — 호그와트 6학년, 또 하나의 해", 고지에 "등장인물은 모두 성인" 추가.
- 색상: 깊은 남색 배경, 양피지색 제목.
- 스토리의 비밀(변화·환영)을 암시하는 요소 없음.

## 목표 연출(미구현, 2.5D + CSS)
1. 로딩: 금빛 선으로 그려지는 로고(SVG stroke-dashoffset), 0.8~1.2초.
2. 안개 낀 호그와트 성: 하늘 / 원경 성 / 안개 / 근경 나무 4레이어 이미지.
3. 마우스 시차: 레이어별 0.5~3% 이동(requestAnimationFrame, pointermove). 터치 기기에서는 기기 기울기 대신 고정.
4. 빛과 입자: 창문 불빛 깜빡임(opacity), 반딧불 같은 입자 20~30개(CSS animation). 저사양·움직임 줄이기에서 정지 이미지.
5. 메뉴 버튼: 호버 시 금빛 테두리 확산, 클릭 시 짧은 섬광.
6. 새 게임: 카메라 전진(scale 1→1.15 + 페이드) 0.9초 후 프롤로그 암전과 연결.
7. 폴백: 이미지 미존재 시 현재 그라데이션 타이틀.
- Three.js 등 3D 라이브러리는 필요성이 확인되기 전까지 도입하지 않는다.
- 성능 예산: 레이어 이미지 총 1.5MB 이하(webp), 첫 화면 2초 이내.

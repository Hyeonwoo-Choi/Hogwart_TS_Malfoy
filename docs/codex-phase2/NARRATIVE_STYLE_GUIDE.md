# NARRATIVE_STYLE_GUIDE — Phase 2 집필 계약

기존 [프로젝트 문체](../NARRATIVE_STYLE_GUIDE.md)를 대체하지 않고 장면 유형별 수용 기준을 추가한다. 해리 1인칭 제한 시점. 현대 웹소설의 리듬·정보 배치를 참고하되 특정 작품의 고유 문장·비유를 복제하지 않는다.

## 공통 WRITING 계약

- 보이는 행동/소리/물건→해리의 잠정 판단→상대의 말/행동→선택의 순서. 타인 속내의 정답을 독자에게 대신 알려 주지 않는다.
- 긴 문장은 공간·인과를 정리할 때, 짧은 문장은 판단/충격/중단에 쓴다. 모든 장면을 동일한 짧은 문장 패턴으로 만들지 않는다.
- 강한 어휘는 무엇이 달라졌는지 구체적으로 보여 줄 때 사용한다. 추상적 감정 명사·강조 부사를 쌓지 않는다.
- 행동 뒤 같은 감정을 설명하는 결론을 지운 뒤 읽어 본다. 이해되면 해설을 다시 넣지 않는다.
- 한 장면의 모티프는 기존 가이드처럼 제한한다. 시선·입꼬리·한 뼘·침묵을 모든 인물의 기본 반응으로 반복하지 않는다.
- 끝은 새 관찰/선택의 비용/기한/상대의 거절 중 하나로 남긴다. 매번 “평범하게 끝나지 않았다” 같은 예고 문장으로 닫지 않는다.
- 관찰/추정/전언/거짓말을 문법과 출처로 구별한다. 거짓 대사는 세계관 확정 사실로 수첩에 옮기지 않는다.
- 선택지 문구는 해리가 이해할 수 있는 행동만. 정체를 아는 장면에서는 이름을 자연스럽게 써도 되며, 모르면 물건·소리·위치로 단서를 준다.

## 장면 유형별 작성·검수

| 유형 | 장면 구성 | 감정·리듬 | 종료·검수 |
|---|---|---|---|
| 미스터리 | 같은 물건의 이전/현재 차이→서로 다른 가설→확인 행동 | 세부 관찰은 길게, 이상을 깨닫는 판단은 짧게 | 원인 확정 전 설명 금지. 독자에게도 선택 근거를 미리 보여 줌 |
| 갈등 | 두 사람의 양립 안 되는 목표→구체 요구→거절/비용 | 설명 대결 대신 질문·말 끊김·물건 놓기 | 누가 무엇을 포기했는지. 화난 인물을 정답 설명 기계로 쓰지 않음 |
| 액션 | 사람/출구/장애물 위치→행동→충돌→재판단 | 타격마다 긴 비유 금지, 인과가 읽히는 짧은 전환 | 부상/징계/도구 손실 다음 장면에 남음. 두 장소 동시 목격 금지 |
| 친밀감 | 인물 목적 속 접근→상대 반응→대상 행동의 허락→선택 | 말보다 거리·손·눈높이; 해석을 덜고 멈출 여백 | 수락/보류/거절 모두 인물의 다음 목적 유지; 이후 행동 1개 |
| 배신 | 기존 약속/정보 범위→어기는 행동→누가 어떻게 알게 됨 | 즉시 감정 정답 대신 어조·호칭·접근권 변화 | 발각 없이 상대가 알아채는 전개 금지. 피해 수습 과제 남음 |
| 반전 | 이미 본 단서 재배치→기존 가설의 결함→검증 | 긴 설명보다 독자가 앞 단서를 다시 이해할 순간 | 설치 없는 새 능력/독심으로 해결 금지; KN 확정 시점 일치 |
| 관계 회복 | 책임 사실→상대 피해→구체 수습→상대 결정 | 사과 뒤 즉시 따뜻해지기보다 행동의 작은 변경 | 용서·자료 접근·연애 재결합은 별도. 상대 보류 허용 |

## 인물 목소리

| 인물 | 주된 언어/행동 | 피할 반복 |
|---|---|---|
| 헤르미온느 | 조건을 수정해 묻고 기록을 바로잡음; 확신이 흔들리면 말 고침 | 모든 친밀감을 가설/실험 농담으로 치환 |
| 지니 | 직구 질문·경쟁·본인 속도를 정함; 놀라면 먼저 물러설 수도 | 해리의 보호를 항상 칭찬하는 수동 반응 |
| 루나 | 구체적인 사물 관찰·질문 사이 간격, 출처 보호 | 모든 비밀을 직감으로 정확히 앎 |
| 판시 | 호칭·거래 범위·공개 체면, 작은 주도권 이동 | 늘 도발만 하거나 드레이코 심부름으로 목적 소진 |
| 드레이코 | 자기 능력·경계·실무, 부탁도 조건을 붙임 | 여성 신체 희화화·회복이 연애의 보상·도움 즉시 수용 |
| 론 | 실제 팀 역할·장난·경쟁의 손실, 자기 결정 | 해리 연애에 반응만 하거나 무한 조력 |

## 연출과 원고의 일치

- 샷 카드에 관찰 가능한 표정·자세·거리·가림·시선·초점을 적는다. 숨겨진 감정 수치에서 표정을 자동 선택하지 않는다.
- 드레이코 표현 표정 비율 등 기존 가이드 제한을 지킨다. 공개 환영과 사적 true는 원고와 show 옵션을 함께 점검한다.
- pause는 실제 엔진 지연인지 수동 페이지 구분인지 명시한다. 현재 0ms cue에 기대어 침묵 시간이 구현됐다고 쓰지 않는다.
- 모바일 크롭은 얼굴·손·허락 대상 행동이 잘리지 않는지 375px에서 확인. 접근 중 중단 선택이 애니메이션에 가려지면 미완료.
- reduced motion에서는 움직임 대신 구도·문장/컷으로 의미를 보존한다. 이미지 레퍼런스 일치는 원본 확보 후만 판단한다.

## 납품 검수

1. 계약 ID·날짜·장소·동시 행동·소지품 확인.
2. 해리의 기존 KN/선택으로 이해 가능한 문장인지 확인.
3. 소리 내어 읽어 길이·반복·인물 목소리 확인.
4. 선택마다 비용과 다음 행동이 다르게 보이는지 확인.
5. 퇴고 diff에서 조건/효과/ID/일정의 우발 변경이 없는지 확인.
6. QA 자연 재생과 수동 원고 검수를 분리해 보고.

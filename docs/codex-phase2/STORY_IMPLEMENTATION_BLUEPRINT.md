# STORY_IMPLEMENTATION_BLUEPRINT

> 연결 후 B 사본에서 Claude의 Ch3 본편 연결·후속과 판시 회상 수정이 확인됐다. 아래 연결 절차는 계약이며 이미 반영된 부분을 다시 구현하라는 지시가 아니다. 현재 검증은 QA_RESULTS (LOCAL ONLY: QA_RESULTS.md, 과거 PC별 결과)의 A/B 구분을 따른다.

2026-10-22 Phase 2 구현 골격. **권고안이며 정본 확정 아님**. 원본 Codex/Claude 문서와 엔진·UI·시나리오는 보존했다. 기존 공통 사건은 유지하고 경로별 사건 결산을 결합한다.

## 적용 경계

- 축=A 기록/증거, B 팀/경쟁, C 공간/관찰, D 사회적 거래/증언, E 마법/비밀/경계. 축은 인물 전용 연애 루트가 아니다.
- 기존 선택/플래그/엔딩은 BRANCH_MAP가 기준. 이 문서의 proposal: 상태와 Cxx_A_* ID는 설계용이며 새 엔진 키가 아니다.
- Ch1~4는 상세 계약 60장면, Ch5~14는 사건 계약 50개다. 새 대사·원고가 완성된 것으로 세지 않는다.
- Ch5 이후 구체 일자는 제안 월 범위다. 실제 코드 일정이 정해지면 원고보다 먼저 고정한다. 전원 성인 AU, 해리 제한 시점.
- 공통 필수 K/S 체험은 현 구현 의미를 유지한다. Ch13 탑 현장 선택화는 미확정 대안으로 별도 남긴다.

## 구현 비용·감정 예산

- 3장면은 사건의 도입/조사/결정을 나눈 계약이다. 기존 장면과 합칠 수 있으며 60개 신규 파일/장면을 의무 생성하지 않는다.
- 기존 Q/L/W 선택 효과를 우선 보존한다. 추가 감정 수치는 아직 미정이며 2챕터 단위로 합산한다. 반응 대사 뒤 장면 끝 fx, 같은 장면 판정 보상 선반영 금지.
- 높은 능력치는 추가 방법만 열고 저능력치도 도움 요청/관찰/철수로 핵심 진행 가능. UI에서 문턱·보상·성장 수치 노출 금지.
- 새 저장 구조/arcs/rep 도입은 별도 호환성 결정. 사건 요약이 원래 선택·허락·약속 이력을 덮어쓰지 않는다.

## 사용자 결정이 필요한 충돌

1. Ch13 K-20 현장 직접 체험을 공통 유지할지 선택화할지. 이번 기본 계약은 유지, 병행 역할은 그 전 행동·동료 보고로 추가한다.
2. Ch6/8 공통 핵심 공개를 어디까지 선택적 직접 경험으로 바꿀지. 현 구현 변경은 보류하고 KN 없는 대체 전개를 명시한다.
3. Ch2 E의 원리 설명 수준. 기본 권고는 위험한 조사를 허용하되 관찰 사실만 확정하고 치료/원상복구 과제로 전환하지 않는 것.

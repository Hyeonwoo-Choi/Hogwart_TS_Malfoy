## Ch3 즉시 구현 순서

1. 기존 ch3_open의 제목·월요일 도입과 구금 본문을 분리. 새 도입은 아침, 구금은 저녁.
2. 기존 W-01~05의 문구·키·플래그 의미를 보존하고 계약의 alias로 연결. C03_*는 설계 참조일 뿐 재명명 지시가 아니다.
3. W-01은 원본 보관/공유/파기의 다른 자료 접근을 Ch4에 이월. 파기해도 필수 본편은 막지 않음.
4. W-02는 설명/혼자 보충/위임을 실제 팀 행동으로 구별. 케이티는 추격꾼, 해리는 수색꾼이므로 같은 자리 경쟁으로 쓰지 않음. 21시 뒤 훈련 자동 허가 금지.
5. W-03은 실제 선택으로 존재하는 실/분필/봉쇄만 관찰·삭제. 일과 밖 time+1로 시간이 흘렀다고 가정하지 않음.
6. W-04는 월요일 약속 판단만 재생. 수요일 10/2 만남·불참은 10/1~3 일과 중 후속으로 분리. 판시의 경계 반응에는 공유를 알게 된 목격/전언이 필요.
7. W-05의 손상은 관찰된 목재 변화만. 론은 협력 범위·대가를 결정하고 교수는 보고 사실만 안다. 치료·맹세·임무 결론 금지.
8. v2c3_join END를 실제 구금 후속으로 연결하고 CH3_SCENARIO/도달성 MAIN에 포함. G 일반도 끝까지 보장.
9. 새 게임→Ch3 종료 자연 검사와 프로토타입 강제 진입 검사를 분리. 기존 망토 반환·S-01 분위기·EH-01 문턱·K-07 보존.

## 선택·상태 수용 기준

- 불참/거절은 즉시 같은 정보를 주지 않는다. 다음 챕터 대체 훅은 원래 선택의 비용·신뢰를 지우지 않는다.
- 인물을 아직 모르면 이름·연애 루트·보상·장래 결과를 선택지에서 말하지 않는다. 이미 정체가 드러난 장면의 자연스러운 이름은 허용.
- 자료의 소유·위치·발신자·열람/공개 허락을 구별한다. 물건 없는 사람을 따라가 그 물건의 인장을 보는 초안은 사용하지 않는다.
- 지식은 관찰/전언/추정별로 기록. 선택 전후 수첩 문구와 지식 변화가 일치해야 한다.
- 감정 변화는 수치 총합보다 상대가 무엇을 바꾸어 행동하는지 먼저 작성한다. 새 수치는 예산 승인 전 미정이다.
- WRITING은 Claude의 역할: 실제 대사·심리·감각·행동·문장 리듬·카메라를 완성하되, 상태/시간/지식 계약은 임의 변경하지 않는다.

# CHARACTER_RELATIONSHIP_BLUEPRINT

전원 18세 이상. 친밀은 사건 해결 보상이 아니며 거절·보류·중단을 존중한다. R1~R4 V2 개정을 우선하고 R4는 합의 뒤 전환/여운으로만 암시한다. 노골적 장면은 작성하지 않는다. 참고 이미지 원본 일치는 미확인이다.

## 주요 관계 장면 카드

각 카드의 실제 대사·심리·표정·리듬은 Claude의 WRITING 영역이다. 수치 임계값은 기존 엔진 조건을 우선하고 새 수치는 미정이다.

### 헤르미온느 — REL_1

- 관심/긴장(R1~R2): 해당 사건에서 서로 목적을 확인한 뒤, 상대가 먼저 시간을 요청. 조건을 고쳐 묻고 자료를 함께 놓는다. 선택은 더 머무르기/목적만 마치기/다음으로 미루기. 시간이 다른 활동과 충돌하며 사건 결말은 모두 가능.
- 신뢰/회복: 서고 위반을 인정하고 원본·공동 명의를 복구. 전제는 실제 갈등 이력+책임 설명. 상대는 화해/보류/자료 접근 철회를 정한다. 해리의 사과 버튼 하나로 REPAIRED를 강제하지 않는다. 소비=C03_A_resolve, C07_A_resolve.
- 진전(R3): 기존 shared event+신뢰/단계+해결되지 않은 배신을 검사. 검증 언어로 거리를 지키되 숨/손의 망설임. 행동 대상이 분명한 허락→수락/보류/거절. 접촉은 상호 확인 뒤만. 거절 벌점 없음, 상대의 아쉬움·다음 목적은 남음.
- 사적 친밀(R4 후보): 개인 비밀 공유와 사적 공간의 맥락, 높은 신뢰, 현재 의사를 별도로 확인. 상대가 장소·중단 방식을 정하고 해리도 거절. 전환 뒤 직접 묘사 없이 끝낸다. 모두에게 같은 단계/날짜를 강제하지 않는다.
- 다음 행동: 다음 만남에서 자료/조사/발표의 접근 범위와 부탁이 바뀐다. 기록·수치만 바뀌면 미완료. 후속 소비=C07_A_resolve.
- 샷: 도입 wide의 물건/서로 거리→행동하는 손/시선 insert→허락 대화 eye-level medium→상대가 멈추거나 다가올 때 카메라 위치/초점 전환. 표현별 실제 자산·몸 자세가 필요; scale만으로 완료 불가.
- 검수: 진입 참/거짓·합법 자연 prefix·수락/보류/거절·그 뒤 다른 행동을 각 1개 증인으로 확인. 목격/전언 없는 질투 대사는 금지.

## 질투·소문·다중 관계

- 현재 엔진 reactions는 직접 목격 recent/witnesses 중심이다. 전언 기능이 구현됐다고 가정하지 않는다. 신뢰할 수 있는 전언은 발신자·수신자·날짜·무엇을 들었는지 설계하고 구현 후 검증한다.
- 평범한 만남/경쟁/호기심/질투/서운함을 구별한다. 관계 stage와 romance가 높아도 모르면 반응하지 않는다. 미래 날짜 목격도 증거가 아니다.
- Ch11에서 각 상대가 질문하며 현재 관계와 다자 동의를 따로 정한다. 모두 accepted가 아니면 자동 다자 성립하지 않는다. 일부 거절을 전원 관계 파기로 처리하지 않는다.
- 친밀 장면마다 metadata의 조건 문자열/대체 경로/사후 소비를 실제 시나리오와 맞춘다. 인물별 장면 수를 기계적으로 같게 만드는 대신 기회·고유 목적·후속 결산을 보장한다.

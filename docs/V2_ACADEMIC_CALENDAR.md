# V2_ACADEMIC_CALENDAR — 학사 일정 · 월별 게시판 · 기간 한정 행사

> 상위: [V2_DESIGN.md](V2_DESIGN.md), [V2_MULTI_HEROINE_STORY.md](V2_MULTI_HEROINE_STORY.md). 구현: `data/calendar.ts`(데이터·파생), `engine/core.ts`(`listActions`·`pickEvent`), `ui/Board.tsx`, `ui/MapView.tsx`, 장면 `data/v2c1e.ts`. 플래그·선택 ID는 [BRANCH_MAP_V2.md](BRANCH_MAP_V2.md).

## 1. 데이터 모델 [구현]
- `CalendarEvent`: `id`, `kind`(public 학교 행사 / appointment 사전 약속 / plan 해리의 계획), `date`(MM-DD), `slots`(시작 가능 시간대 0 오후1·1 오후2·2 저녁), `place`, `dur`, `announce`(게시 시작일), `cond`(약속·계획 성립 조건), `notice`·`terms`·`lore`(게시판 문구), `scene`.
- 참가 기록: `GameState.board = { done: {행사id: 결과}, read: [공지id] }`(선택 필드, 구세이브는 빈 기록으로 보정). 결과는 장면의 `ev:<id>=<결과>` 효과(참가 직후 `joined`).
- 파생(저장 안 함): `openEventsAt(state, loc)`, `boardView(state)`(월별 목록·상태·충돌), 지도 마커 ★.
- 조건 변수: `EV_<행사id>`(참가 여부), `HERE_<히로인>`(방금 활동한 자리에 일정표상 그 히로인이 있었는가, `routine.span`).

## 2. 규칙 [구현·테스트]
- **정확한 날짜·시간대·장소**에서만 지도에 행사 행동이 생긴다(전 조합 전수 테스트). 장소가 닫힌 시간(도서관 저녁 등)은 열리지 않는다.
- **한 번만**: 참가 기록이 장면 시작 전에 남는다. 장면 도중 재클릭·저장→복원에서 시간 소모·보상이 중복되지 않는다(시간은 행사 `dur`만큼 한 번).
- **놓친 행사**: 시간이 지나면 게시판 "지난 일정"에 "놓침"으로 남고 다시 열리지 않는다. 핵심 단서를 단 한 번의 행사에만 두지 않는다(약속 단서는 7층 도입에서 대체 문장이 있고 챕터는 항상 진행된다).
- **충돌**: 같은 시간대의 두 행사(목 오후2: 도서관 약속 / 경기장 공개 연습)는 장소가 달라 하나만 갈 수 있다. 게시판이 "둘 중 하나만"이라 안내한다.
- **시간 건너뛰기**: 일과 종료·건너뛰기 뒤에도 기록은 그대로다. 월이 바뀌면 그 달의 일정만 보이고(경계 테스트), 공지 전(`announce` 이전)에는 보이지 않는다.
- **공개 정보만**: 게시판에는 학생이 알 수 있는 공지만 있다. 돌발 사건·비밀·성립하지 않은 약속은 존재를 알리지 않는다(테스트: 게시판 JSON에 "금·균열·7층·말포이" 없음). 읽기 전용(읽음 표시 외에 시간·수치 불변).

## 4. UI [구현 · 브라우저 QA 결과는 보고서]
- 지도 헤더의 "게시판" 버튼 → 모달(앞으로의 일정 / 지난 일정, 날짜·시간대·장소·상태·공지·참가 조건·세계관 설명·충돌 안내, 읽지 않은 공지 ●). 행사가 열린 장소의 마커는 ★과 금색 표시, 장소 패널 맨 위에 "★ 행사" 행동. 기존 상단 알림창은 추가하지 않았다.

## 5. 설계 [미구현]
- 챕터 2 이후 월별 행사 확장(10월 ~ 6월), 행사 선택 중 저장 UI(선택지 도중 저장은 이미 가능), 다음 달 예고, 놓친 행사의 후속 대사(현재는 기록만), 호그스미드 주말·천문 관측 장소 추가.

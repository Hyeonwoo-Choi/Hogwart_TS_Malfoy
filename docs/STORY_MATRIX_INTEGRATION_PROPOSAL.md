## 2. A~E 정의: 충돌처럼 보이지만 같은 축을 가리킨다
① 각 행의 주제를 모아 보면 축이 챕터를 넘어 일관된다.
| 축 | ①의 행(챕터별 이름) | 일관된 주제 |
|---|---|---|
| A | 각주의 빈칸 → 기록과 연구 → 진술의 빈 줄 → 수리 대출 → 인계 기록 → 실험 동의 → 공저 → 회신 → 검증 시험 → 보호 신청 → 검증회 → 신고 준비 → 인계 → 진술 | 기록·증거·진술의 정확성과 책임 |
| B | 겹친 시간표 → 경기와 경쟁 → 복귀 심사 → 관중석 균열 → 구조 현장 → 복귀 경쟁 → 전술 → 슬럼프 → 선발 책임 → 경기·경계 → 역할 → 대피 연합 → 호송 → 팀 | 팀·경쟁·동료 안전 |
| C | 일곱 번의 빛 → 통로와 안전 → 우회 통행 → 문과 사과 → 저주 경계 → 소각 흔적 → 지도 출판 → 노트 → 대피 훈련 → 폐쇄 계획 → 지도 공유 → 차단 → 봉쇄 → 지도 | 공간·통로·관찰과 안전 |
| D | 접힌 쪽지 → 거래와 책임 → 증언의 값 → 운송표 → 운송과 소문 → 방학 초청 → 예산 → 조건부 초대 → 거짓 전언 → 물자 차단 → 증인 보호 → 보호·협상 → 이동 → 거처 | 거래·증언·사회적 자율 |
| E | 늦은 불빛 → 사라진 흔적 → 경계선 → 남는 반응 → 목격자 → 소매의 사실 → 평온의 약 → 편지 → 비밀 시험 → 완성 → 목표 확인 → 개인 결정 → 탑 → 관계 | 불안정한 마법·사생활·경계·개인의 비밀 |
- 즉 ①의 "A~E의 뜻은 챕터마다 바뀐다"는 **행 세부가 바뀐다**는 뜻으로 읽으면 ②와 같다. 사용자 지시("Ch2의 기존 A~E를 확장")와 구현된 `FLAG_P2_RESEARCH/PITCH/SECRET/SLY`가 **축 연속성**을 전제하므로, 권고: **"축 = 고정 주제, 행 = 챕터별 계약"**으로 용어를 맞춘다.

## 5. 통합 권고(정본 아님, 구현 호환 사항만)
1. **용어**: "축(Axis) = 고정 주제 / 행(Row) = 챕터별 사건 계약"으로 정의를 한 줄씩 양쪽 서문에 추가(원본 수정 없이 이 문서가 기준 문장 제시).
2. **진입**: 훅은 항상 노출 + 긴 장면 우선순위(② 3장). 구현 단위: `v2c3_route`가 이미 이 방식(프로토타입).
3. **ID 레지스트리**: 설계 번호(`C03-A`)와 엔진 ID(`FLAG_P3_A_*`/`W-01`)의 대응표를 `BRANCH_MAP_V2.md`에 추가.
4. **블라인드 문구**: 플레이어 대면 선택 문구는 ① 표를 기준으로 쓰되, 인물 이름은 정체가 밝혀진 뒤에만 쓴다.
5. **X-1·X-2는 사용자 결정 사항.**

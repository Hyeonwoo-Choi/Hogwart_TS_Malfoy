# UI_SPEC — 화면·조작·반응형

원칙: 스토리 화면에는 능력치·호감도·지도 UI를 표시하지 않는다. 1920×1080 고정 레이아웃과 단순 전체 축소(transform scale)는 금지한다. 모든 크기는 상대 단위(`vw`·`dvh`·`rem`·`clamp()`)와 CSS Grid/Flex로 재배치한다.

## 1. 게임 모드(상태 기계)

| 모드 | 설명 | 지도 | 대화 |
|---|---|---|---|
| `TITLE` | 타이틀·불러오기·고지 문구 | 잠금 | — |
| `STORY` | 메인 스토리 | **잠금** | 활성 |
| `EVENT` | 일과 중 특별 이벤트 | **잠금** | 활성 |
| `ROUTINE` | 자유 일과(지도·활동 선택) | 활성 | 만남 이벤트는 `EVENT`로 전환 |
| `MENU` / `BACKLOG` / `SETTINGS` / `SAVELOAD` | 오버레이 | 직전 모드 유지 | 일시정지 |

전이 규칙
1. `STORY`가 정상 종료(`end` 노드)된 뒤에만 `ROUTINE`으로 전환 → 지도 활성.
2. `ROUTINE` 중 특별 이벤트 발생 → `EVENT`(지도 잠금) → 종료 시 남은 슬롯으로 `ROUTINE` 복귀(슬롯 소비 규칙: GAME_BIBLE 5.1).
3. 일과 종료(슬롯 0) → 다음 `STORY`.
4. 잠금 상태에서는 지도 버튼을 **렌더링하지 않는다**(비활성 표시도 하지 않음).

대화 내부 상태: `IDLE → TYPING → WAIT_CLICK → (CHOICE | AUTO_WAIT | SKIP)`.
- `TYPING` 중 입력 → 현재 대사 즉시 완성(`WAIT_CLICK`). 완성 후 입력 → 다음 노드.
- `CHOICE`: 대사 진행·자동·스킵 모두 중단. 선택 확정 전에는 어떤 시각 변화도 없음.

## 2. 화면 레이아웃

레이어(아래→위): 배경 / 메인 캐릭터 / 대사창+이름표 / 선택지 패널 / 상단 메뉴 / 오버레이.

### 2.1 반응형 규칙

| 구분 | 조건 | 배경 | 캐릭터 | 대사창 | 선택지 | 상단 메뉴 |
|---|---|---|---|---|---|---|
| 데스크톱/노트북 | 너비≥1024 | `cover`, 은은하게(채도·명도 낮춤) | 중앙~중앙 우측, 높이 `min(85dvh, 900px)`, 비율 유지(`contain`) | 하단, 너비 `min(1100px, 92vw)`, 최대 높이 32dvh, 반투명 | 대사창 바로 위 중앙 세로 정렬 | 우상단 아이콘 메뉴 |
| 태블릿 | 600~1023 | 동일 | 높이 70dvh | 너비 94vw | 동일 | 우상단 |
| 모바일 세로 | 너비<600, 세로 | `cover` + `object-position` 조정 | 높이 58dvh, 중앙, 얼굴이 대사창에 가리지 않도록 상단 정렬 | 하단 너비 100vw, 최대 높이 38dvh | **하단 시트**(최대 높이 55dvh, 스크롤) | 햄버거 |
| 모바일 가로 | 높이<500 | 동일 | 상반신 크롭 모드, 우측 정렬 | 하단 너비 100vw, 최대 높이 40dvh | 좌측 영역 오버레이(스크롤) | 햄버거 |

공통 규칙
- **대사창은 캐릭터를 가리지 않는다**: 화면은 `[캐릭터 영역 1fr][대사창 고정 높이]` 그리드이며 캐릭터는 대사창 위 영역 안에서만 그려진다. 선택지 패널은 대사창 위에 떠서 선택 중에만 캐릭터 일부를 가릴 수 있다(반투명 패널, 화면 안·대사창과 겹치지 않음).
- 모바일은 별도 하단 시트 대신 같은 중앙 패널을 전체 폭으로 사용한다(스크롤 가능).
- 세이프 에어리어(`env(safe-area-inset-*)`) 적용. `dvh` 사용(주소창 변화 대응).
- 텍스트: `clamp(15px, 1.1vw + 11px, 20px)`, 설정에서 3단계 확대. 이름표는 대사창과 겹치지 않는 상단 좌측.
- 이미지는 `object-fit: contain`(캐릭터)·`cover`(배경)로 비율 유지. 레이아웃 시프트 방지를 위해 `aspect-ratio` 지정.

### 2.2 대화창
- 반투명 어두운 패널, 고딕 풍 구분선(텍스트 가독성 우선).
- 발화자 이름(없으면 나레이션은 이름표 숨김), 타이핑 효과, 진행 표시 아이콘(WAIT_CLICK 때만).
- 대화창 숨기기: `H` 키 또는 버튼. 숨김 중 클릭은 복원만 수행하고 진행하지 않는다.

### 2.3 선택지
- 세로 정렬, 최소 높이 48px, 간격 10px, 긴 문장 줄바꿈, 패널 `overflow-y: auto`(최대 높이 규칙은 2.1).
- 숫자 배지 1~9(키보드 선택).
- 호버: 배경·테두리 색 변화만. **캐릭터·배경·표정 변화 금지, 수치 팝업 금지.**
- 클릭 확정 후에만 결과 장면·표정 변경. 선택 확정 전 확인 팝업은 두지 않는다(플레이어 선택을 임의로 확정·무효화하지 않음).
- 시간제한 선택지(K-09, K-20만): 얇은 진행 바. 설정으로 완화(2배)/해제. 해제 시 "망설임" 결과를 명시 선택지로 제공(BRANCH_MAP 2장).

## 3. 조작

| 입력 | 동작 |
|---|---|
| 클릭 / Enter / Space | 대사 진행(타이핑 중이면 즉시 완성) |
| Esc | 메뉴(열려 있으면 닫기) |
| 숫자 1~9 | 선택지 선택 |
| Ctrl(누르는 동안) | 읽은 대사 스킵 |
| 마우스 휠 위 | 대화 기록 열기 |
| H | 대화창 숨기기 |
| A | 자동 진행 토글 |
| 터치 | 탭=진행, 하단 아이콘으로 자동/스킵/기록/숨기기 |

텍스트 입력 필드나 오버레이 활성 시 단축키는 오버레이가 우선한다.

## 4. 편의 기능

| 기능 | 규칙 |
|---|---|
| 대화 기록 | 최근 200줄. 화자·대사·선택한 선택지 표시. 휠 위/버튼. 닫으면 진행 상태 유지 |
| 자동 진행 | 완성 후 `1.2s + 40ms × 글자 수`(배속 설정) 대기. `CHOICE`·메뉴·기록·숨김 시 **중단** |
| 스킵 | 기본은 **읽은 대사만**(`read.lineIds`). 미읽음 대사·선택지·챕터 종료에서 정지 |
| 대화창 숨기기 | 2.2 참조(H 키·버튼, 숨김 중 클릭은 복원만) |
| 타이핑 속도 | 느림/보통/빠름/즉시 |
| 시간제한 완화 | 보통 / 2배 / 해제 |
| 저장·불러오기 | 수동 10칸 + 자동 1칸. 슬롯에 챕터·날짜·시간대·저장 시각·썸네일(플레이스홀더 허용) 표시 |

저장 내용: GAME_BIBLE 7.1의 상태 객체 전체(장면·대사 위치·감정·선택·능력치·일과 상태·사건 기록·읽은 대사·설정). 복원 시 해당 노드의 **대사 시작 지점**(선택지 화면이면 선택지 직전)으로 복귀하며, 지도 잠금 상태도 모드에서 재계산한다.
자동 저장: 챕터 시작, 선택 확정 직후, 일과 종료 시점.

## 5. 일과 지도

- `ROUTINE` 모드에서만 표시. 장소: 대연회장 / 도서관 / 마법약 교실 / 퀴디치 경기장 / 안뜰 / 호수 / 7층 복도 / 기숙사 휴게실 / (챕터별 해금).
- 슬롯(오후1·오후2·저녁) 선택 → 장소 선택 → 활동 선택(공부/마법 훈련/퀴디치/대화/휴식).
- 드레이코 만남은 **GAME_BIBLE 3.2 일정표**와 일치할 때만 발생(`scheduleOverride`는 챕터 데이터에 명시).
- 능력치·피로 UI는 지도 화면에서만 표시한다(스토리 화면 금지). 호감도·감정 수치는 어디에도 표시하지 않는다(`?debug=1` 제외).

## 6. 에셋 정책

- 이미지 생성 도구가 없으므로 **초기 제작은 플레이스홀더로 진행**한다. 모든 이미지는 `assets/manifest.json`에 등록한다.
```json
{"id":"draco_smirk","path":"assets/char/draco_smirk.svg","status":"placeholder","note":"실루엣+라벨"}
```
- `status`: `placeholder` | `final`. 존재하지 않는 경로는 참조하지 않는다(로더가 manifest에 없는 ID를 거부).
- 플레이스홀더는 SVG/CSS 그라디언트 + 라벨("PLACEHOLDER · 드레이코 · 비웃음")을 화면에 표시해 미완성임을 숨기지 않는다.
- 최종 보고에서는 `final` 개수와 `placeholder` 개수를 구분해서 보고한다.
- 필요한 에셋 최소 목록(챕터 1): 배경 6(기차 내부/대연회장/마법약 교실/경기장/도서관/7층 복도 야간) · 드레이코 표정 10종 · 해리 표정(필요 시) · 조연 입상 4(헤르미온느·론·지니·루나) + 슬러그혼.

## 7. 접근성·성능

- 모션 감소 설정 존중(`prefers-reduced-motion`): 타이핑·페이드 최소화.
- 대비비 4.5:1 이상. 선택지·메뉴 키보드 포커스 표시.
- 이미지 지연 로드와 다음 장면 프리로드. 초기 로드 3MB 이내(플레이스홀더 기준).

| 필수 QA | 검증 방법 |
|---|---|
| 감정 분기 | EH-01~EH-08을 수치 주입(`?debug=1`)으로 A/B 조건 양쪽 재생, 대사·행동 차이 확인 |
| 과거 선택 | 같은 장면을 `FLAG_ACCUSED_PUBLIC` 유/무로 재생해 Ch6 대사·RS 차단 확인, DE-xx 재생 |

| 자동 진행 | `CHOICE` 진입 시 자동 대기 타이머가 취소됨 |
| 저장 복원 | 선택 후 저장 → 새로고침 → 불러오기. 장면·선택 기록·감정·모드·슬롯 유지 |

## 2026-10-20 갱신 (챕터 1~2 재설계 회차) — 아래 규칙이 위의 구버전 문구보다 우선
- **스포일러 금지**: 플레이어 화면·DOM에는 인물 이름만. 표정 코드·외형 상태(기본/환영/진짜)·에셋 ID·"PLACEHOLDER/플레이스홀더"·내부 파일명 금지. 내부 속성(data-expr 등)은 `?qa`·`?debug=1`·테스트에서만 노출(`env.devAttrs()`). 타이틀의 개발 정보도 동일.
- **대화창 구조**: `.dialogue-wrap`(위치) > `.nameplate`(이름표, 스크롤 영역 밖) + `.dialogue`(스크롤 본문). 이름표는 잘리지 않으며 말줄임 처리. 본문 최대 폭 42em.
- **타이포그래피**: 본문·대사·선택지 `Pretendard → Noto Sans KR → Malgun Gothic`, 제목·이름표 `Noto Serif KR → Nanum Myeongjo → Batang`. 폰트 파일은 다운로드하지 않는다(설치된 경우만 사용). 본문 16~19px(clamp), 행간 1.75, `word-break: keep-all`. 서술은 회청색, 대사는 기본색으로 구분.
- **선택지**: 최소 높이 52px(모바일 44px 이상), 가로 스크롤 없음, 키보드 1~9.
- **연출 큐**: 조명(light-*) 레이어와 효과(fx-*)는 진행을 막지 않는다. `prefers-reduced-motion`에서 흔들림·확대·흐림·마법·섬광 비활성. 저장 복원 직후에는 재생하지 않는다.
- **CG**: 장면 위 프레임. 이미지가 없으면 제목만 있는 프레임. 갤러리는 경험한 장면만.
- **마법사의 기록(도감)**: 메뉴/엔딩 카드에서 열람. 관찰·알게 된 것·약속·선택·장소. 해리가 모르는 사실·내부 ID·수치 없음. 새 지식은 과거 항목에 "다시 보니"로 덧붙임.
- **QA 모드**: `?qa` → 저장 키 `hfd-qa:` 분리, 좌상단 QA 배지, 자동화 핸들 `window.__hfd`.
- **일과 결과**: 서술만(능력치 이름·수치 없음). 능력치 패널은 유지.

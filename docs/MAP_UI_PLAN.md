# MAP_UI_PLAN — 호그와트 지도 인터페이스 (설계, 미구현)

현재: 장소 카드 그리드(MapView) + 능력치 패널. 이번 회차는 카드 UI 유지, 지도는 설계만.

## 1. 구조
- 배경: 성 평면 일러스트 1장(층 구분 없이 주요 장소만). 장소 = 좌표(%) 기반 마커. 이미지가 없으면 현재 카드 그리드로 폴백.
- 마커 정보: 장소 이름, 분위기 한 줄(LOCATIONS.desc), 방문 횟수에 따른 작은 표시(처음/익숙함). 보상·능력치·성장 종류는 표시하지 않는다.
- 시간 슬롯 표시(오후1/오후2/저녁)는 상단 유지.

## 2. 잠금
- STORY/EVENT 중에는 지도 비활성(현재 엔진 규칙 `canOpenMap` 유지).
- 챕터가 지정한 장소만 활성(`routine.locations`). 비활성 장소는 흐리게, 이유는 서술("이 시간엔 문이 잠겨 있다")로.
- 야간 활동은 챕터가 허용할 때만(챕터 1~2는 비활성).

## 3. 인물 위치 정책
- **해리가 알 수 없는 NPC 위치는 표시하지 않는다.** 드레이코 일정표(DRACO_SCHEDULE)는 내부 데이터이며 지도에 노출하지 않는다.
- 예외: 해리가 이미 알고 있는 정보(예: "토요일 밤 7층" — `OB_SAWDUST`·`KN_WALL_DOOR` 획득 후)는 도감에만 기록, 지도 마커에는 쓰지 않는다.
- 조연 위치도 같은 원칙(약속한 장소만 표시 가능).

## 4. 모바일
- 375px 기준: 지도 대신 장소 목록(현재 카드)으로 자동 전환, 또는 핀치 없이 세로 스크롤 가능한 축소 지도.
- 마커 터치 영역 ≥ 44px. 활동 선택 모달은 현재 구조 재사용.

## 5. 구현 순서(제안)
1) 장소 좌표 데이터(`constants.ts`의 LOCATIONS에 x,y 추가) 2) MapView에 지도 모드 토글(이미지 존재 시) 3) 마커 접근성(button, aria-label=장소명) 4) 반응형 폴백 테스트.

# V2_DESIGN — 다중 히로인 관계 시뮬레이션 재설계

> 적용 범위: 브랜치 `v2-multi-heroine`(기준 e3e612d에서 분기). 기존 `iter1-ch1-2-redesign`(챕터 1~8 완성본)은 그대로 보존된다.
> 상태: 프롤로그·챕터 1 구현 완료, 챕터 2~8은 기존 원고 유지(이행 대기), 챕터 9~14 미작성. 챕터 구성은 [V2_CHAPTER_PLAN.md](V2_CHAPTER_PLAN.md), 호환 정책은 [V2_COMPAT.md](V2_COMPAT.md).
> 상세 설계: [V2_HEROINES.md](V2_HEROINES.md)(히로인 서사·질투) · [V2_DRACO_ILLUSION.md](V2_DRACO_ILLUSION.md)(변신·환영 규칙) · [V2_PERCEPTION.md](V2_PERCEPTION.md)(지식·소문) · [V2_CH1_SCENES.md](V2_CH1_SCENES.md)(챕터 1 장면) · [V2_ROADMAP_IMPL.md](V2_ROADMAP_IMPL.md)(로드맵·구현 계획). · [V2_JOURNAL.md](V2_JOURNAL.md)(인물 관찰 기록·용어집·대사 UX) · [V2_CH1_REVIEW.md](V2_CH1_REVIEW.md)(챕터 1 서사 평가) · [V2_UI_TRANSITIONS.md](V2_UI_TRANSITIONS.md)(선택지·지도·장면 전환) · [V2_NOTEBOOK.md](V2_NOTEBOOK.md)(마법 수첩·사건 수첩·활동 장면).
> 기존 설정(GAME_BIBLE)은 유지한다: 성인 AU(전원 만 18세 이상), 해리 1인칭, 챕터 2 말미의 드레이코 변화, 메인 미스터리와 반전.

## 1. 원칙
- 메인 미스터리와 호그와트 생활을 같이 키운다. 모든 히로인은 해리와 무관한 **독립 목표와 사건**을 가진다.
- 로맨스는 선택이다. 우정·라이벌 경로도 끝까지 유효하고 핵심 사건에 도달한다.
- 높은 호감만으로 연애가 성립하지 않는다. 연애는 **장면에서의 상호 합의**로만 성립한다(거절·우정 유지·종료 가능).
- 선택의 결과는 숫자보다 **장면과 대사**로 나타난다. 수치는 표시하지 않는다(도감에는 관계 단계 이름만).

## 2. 히로인(공략 가능 5인) — 독립 목표와 성격
| 인물 | 독립 목표 | 성격·관계의 축 | 관계 진입 조건(요약) |
|---|---|---|---|
| 드레이코 | 가족을 지키는 임무와 정체성(기존 서사 유지) | 신뢰·경계·경쟁심·자율성 | 기존 EH 조건 + 챕터 7 이후 SS 장면 |
| 헤르미온느 | N.E.W.T. 수석 + 룬 문자 논문, 감독생 책임 | 우정·지적 교감·가치관 충돌(규칙 vs 우정). 해리를 무조건 지지하지 않음 | 정직한 협력(숨기지 않기)과 의견 충돌의 해결 이력 |
| 지니 | 퀴디치 주전·차기 주장, "론의 동생·해리의 친구" 이상의 자기 이름 | 장난·직설·독립심. 기다리지 않는다 | 연습·경기에서 대등한 동료로 인정받은 이력, 솔직한 대화 |
| 루나 | 아버지 잡지의 진실성과 자신이 믿는 생물의 증명 | 편견 없는 관찰·정서적 이해. 예언자·단서 제공자로 축소하지 않음 | 그녀의 탐색에 함께한 이력, 판단하지 않는 태도 |
| 판시 | 드레이코와 자기 가문의 체면을 지키는 것, 두려움 감추기 | 선입견·충돌·충성심 → 재평가. 드레이코와의 관계를 존중하며 독립 가능성 | 충돌 뒤 인정과 사과의 이력, 드레이코를 둘러싼 신뢰 |
- 론은 비공략이지만 키퍼 자리·열등감 극복·우정 서사를 가진다(챕터 8 K-15 등).

## 3. 관계 모델(구현: core.ts·cond.ts·save.ts)
- **수치**(`emotions.<id>`): 호감·신뢰·경계(드레이코는 기존 11개 수치). 판시는 새로 추가(`emotions.pansy`).
- **상태**(`GameState.bonds[<id>]`): `stage`(0 서먹/1 아는 사이/2 친구/3 가까운 사이) · `romance`(none / open / together / declined / ended) · `poly`(unasked / asked / accepted / declined) · `seen`(만난 횟수). 초기값: 헤르미온느 2, 지니·루나 1, 판시·드레이코 0.
- **효과**: `stage:<id>+1|-1|=N`, `romance:<id>=open|together|declined|ended`, `poly:<id>=asked|accepted|declined`, `meet:<id>[@증인,...]`.
- **조건식**: `stage.<id>`, `romance.<id>`(0~4), `poly.<id>`(0~3), `partners`(연인 수), `MET_<id>_<N>`(최근 N일 내 만남), `SAW_<관찰자>_<id>_<N>`(그때 관찰자가 같은 자리에 있었다).
- **지식 단계**(구현됨): `bonds[id].know`(0~4, 선택 필드·기본 0, 론 포함) · 효과 `know:<id>=N|+N|-N` · 조건 `know.<id>` · 도감·UI 비표시. 이전 저장은 0으로 보정, Ch2 S-02 B 이력이 있으면 판시=1. 비공략 인물(론)은 `romance:`/`poly:` 효과 불가. 의미는 [V2_PERCEPTION.md](V2_PERCEPTION.md).
- **반응 훅**(구현됨): 조건 `REACT_<관찰자>_<대상>`(최근 3일 목격 시 0 없음/1 질투/2 경쟁심/3 호기심/4 서운함/5 무관심). 표는 `src/engine/reactions.ts`(V2_HEROINES 3장), 질투는 연애가 열린 상태(open·together)·가까운 사이에서만 나온다.
- 단계 상승·연애 상태는 **장면 효과로만** 바뀐다(수치 임계값으로 자동 승격하지 않음). `open`은 마음을 알리고 상대가 열려 있는 상태이며 배타적이지 않다.

## 4. 만남 기록과 질투·반응
- 만남 기록(`recent`)은 최근 8개만 유지한다(영구 플래그 남발 금지). 증인은 **일정표상 같은 장소·시간에 있던 사람**으로만 자동 기록된다(서사적 근거가 있을 때만 제3자가 반응).
- 질투 표현은 성격별로 다르다: 헤르미온느 — 직설적인 질문과 공동 작업의 거리 두기 / 지니 — 놀림, 상처받으면 정면 대화 / 루나 — 호기심 어린 관찰 / 판시 — 비꼼과 공격성 / 드레이코 — 자존심과 냉담. 반응은 호감 하락이 아니라 장면(대사)이며 경쟁심·호기심·서운함·무관심도 가능하다.
- 비로맨스 경로의 같은 사건은 "걱정·우정의 긴장"으로 읽히도록 작성한다. 소유욕·통제를 낭만으로 포장하지 않는다.

## 5. 다자 연애(별도 경로)
- 단일·다자·비로맨스 엔딩을 모두 지원한다. 다자는 호감 합산이 아니라 **조건**이다: `romance=open` 이상인 히로인이 둘 이상 ∧ 각자 `poly=accepted`(해리가 솔직하게 알린 장면에서 각자 결정) ∧ 풀리지 않은 기만 플래그 없음.
- 일부 히로인은 다자를 거절할 수 있고(`poly=declined`), 거절은 그 인물의 서사적 실패가 아니다(우정·단일 경로가 유효). 동의 장면은 챕터 11~12에 둔다([V2_CHAPTER_PLAN.md](V2_CHAPTER_PLAN.md) 5장).

## 6. 자유 일과 연동
- 지도·장소·시간·47개 랜덤 이벤트는 그대로다. 히로인은 **주간 일정표**(`HEROINE_SCHEDULE`, 장소 출입 조건과 모순 없음)를 따르고, 일과 노드의 `meets`(히로인 → 장소 → 장면 풀)로 고유 이벤트를 준다. 풀은 순서대로 한 번씩 소비되며 만난 횟수가 적은 사람이 먼저 나온다.
- 중요한 이벤트는 추첨이 아니라 이 스크립트 풀(`meets`)에 둔다. 누구도 매번 만날 필요가 없고, 메인 스토리는 그들을 만나지 않아도 진행된다.
- 드레이코 만남(`encounters`)과 조연 일상(`friends`)은 기존 방식을 유지한다. 한 활동에서는 드레이코 → 히로인 → 조연 → 랜덤 이벤트 순으로 최대 하나만 발생한다.

## 7. UI·수치 공개 정책(UI_SPEC 준수)
- 감정·관계 수치는 어디에도 표시하지 않는다(`?debug=1` 제외). 도감 "관계" 항목에 만난 적 있는 인물의 단계 이름(서먹한 사이~가까운 사이)과 합의된 상태 문장만 기록한다.

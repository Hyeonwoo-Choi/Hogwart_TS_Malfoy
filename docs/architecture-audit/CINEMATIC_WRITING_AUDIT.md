# 연출·문체·성인 관계 감사

2026-10-22. [기준 버전](ARCHITECTURE_COMPARISON.md)·[요구사항 표](REQUIREMENT_AUDIT.md). 첨부 참고 이미지 원본은 이번 감사에서 확보하지 못했다. 참고 이미지와 실제 장면의 일치 여부는 확인 불가다. 화면을 보지 않은 상태에서 코드의 scale 값을 원근감 구현 완료로 평가하지 않았다.

`public/assets/manifest.json`에는 완성 자산이 없고 기본 manifest는 placeholder다. 따라서 기본 SVG·프레임 연출은 있지만 참고 이미지 수준의 그림·포즈·시선이 준비되었다고 볼 수 없다. 이미지 제작/다운로드는 수행하지 않았다.

수용 기준(B09): 장면별 주도 인물, 접근 전후 화면 점유·눈높이·초점·자세·거리·전환·접근 중단 경로를 한 장의 샷 표에 적는다. 서로 다른 2개 장면을 `?qa`에서 모바일/데스크톱으로 확인하고 reduced motion에서도 의미가 유지되어야 한다. 같은 확대를 모든 인물에게 적용하는 것은 차별화의 증거가 아니다.

## 실제 원고 근거

### 판시 — 주도권과 취약성이 이미 작동함

- `v2c2r.ts:378~384`: 길을 막고 다가온 뒤 입꼬리가 흔들린다. 행동으로 우위의 균열을 보여 주며 캐릭터 주도적 접근 요구에 부합한다.
- 다만 걸음 수·한 뼘·입꼬리 변화 뒤 “시험하는 쪽이 … 먼저 흔들리는 순간”이라는 심리 정답을 덧붙인다. 관찰만 남기거나 해리의 추정으로 한정하면 제한 시점과 여백이 좋아진다. 취향/문체 개선(P2)이며 확정 설정 위반으로 판정하지 않는다.
- `L-04 B:387`, 399~403행은 허락을 묻고 답한 뒤 짧은 키스로 이어진다. 동의가 없다고 단정할 근거는 없다. 다만 “가도 돼”가 접근인지 키스인지 흐리므로 해당 행동을 알아볼 수 있는 질문/행동 단서를 명확히 하는 것을 권고한다.
- `L-21:412~430`은 인물이 공간을 제안하고 두 대답 모두 존중한다고 말한다. R4는 전환·암시로 처리되며 노골적 묘사를 더할 필요가 없다.
- 다음 아침 후속이 전혀 없는 것은 아니다(`ch2c.ts:212`). 그러나 금요일 9/27의 열쇠를 일요일 9/29에 “어젯밤”으로 회상한다. 관계별 시간 인과 오류(P1, B02)다.
- 이후 Ch3에서 선택 수락/보류/비밀 약속이 실제 부탁·거리·소문 행동을 바꾸는지는 부족하다. 수치와 기록만으로 후속 반영을 완료했다고 보지 않는다.

### 지니 — 직접성과 자기 속도는 분명하지만 약속 회수가 약함

- `v2c2r.ts:307~324`: 직접 질문하고 해리의 대답에 물러선 뒤, 키스의 시점을 경기 뒤로 정한다. 상대가 자기 속도를 결정하는 점이 좋다.
- `FLAG_GIN_OPEN`의 후속은 확인한 data 소스에서 관계 장면 설정과 `ch2Records.ts:75`의 기록에 머문다. 경기 뒤 약속을 실행·연기·철회하는 고유 장면은 찾지 못했다.
- 수용 기준(B05): 경기 결과 뒤 지니가 약속을 기억하고 현재 의사를 다시 정한다. 해리는 수락·보류 가능하며 결과는 다음 만남의 행동으로 남는다. 승패를 접촉 권리의 보상으로 취급하지 않는다.

### 헤르미온느·루나·드레이코 — 차별성은 유지하고 해설을 줄임

- 헤르미온느 `v2c2r.ts:291~300`: 시간·연구라는 어휘로 보류를 받는 목소리는 차별화되어 있다. 그러나 숨·어깨의 관찰 뒤 성격의 정답까지 설명한다. 대사와 행동으로 이해되는 부분은 덜어낼 수 있다.
- 루나의 관찰 중심 접근은 고백의 언어와 구별된다. 후속에서 위험한 계단 접근을 해리가 허가하는 구조보다 루나가 자기 조사 범위와 제보자 안전을 결정하게 해야 한다. Claude Ch3 상세 70~72행의 어느 선택에도 계속 조사하는 설계는 결과 차이를 명확히 해야 한다.
- 드레이코는 자기수용·실무 협력·연애를 구별해야 한다. Ch3의 거리를 연애 전체 배제처럼 기술하지 않고, 공개 환영·사적 true·해리만 아는 신체 사실을 샷/대사에 함께 검수한다.
- 판시의 연락책/드레이코 대리 답신은 독립 목표를 줄 수 있지만, 남의 이름으로 답하는 행동의 권한·발각·결과를 써야 한다. 능동적인 인물을 반드시 올바른 선택만 하는 인물로 바꿀 필요는 없다.

## 성인 서사를 구현 기준으로 바꾸기

현재 R1~R4 개정은 허용 범위와 동의 원칙을 정의했다. “성숙한 긴장 강화”의 수용 기준은 여전히 부족하다. 강도를 수치 문턱이나 키스 횟수만으로 정의하지 않는다.

| 요구 | 실제 제작 계약 | 검증 |
|---|---|---|
| 끌림·긴장 | 인물별 하나의 자기 목적 속에 접근/머뭇거림/거리 선택을 둠 | 전후 대사 없이 수치만 바뀌는 장면을 완료로 세지 않음 |
| 유혹·도발 | 상대가 왜 지금 다가오는지 목적과 위험을 적음 | 해리 거절 뒤 사건·인물의 목적이 계속됨 |
| 충동 | 규칙 위반/폭로의 즉시 비용+다음 챕터 후속 | 상처·소문·징계·거절 중 실제 인과가 재생됨 |
| 질투 | 목격/전언과 관계 합의를 먼저 정함 | 모르는 인물의 감정 변화·대사 반응 금지 |
| 비밀과 친밀 | 정보 허락·공개 허락·신체 허락을 분리 | 한번의 허락으로 후속 행동을 자동 승인하지 않음 |
| 보류·거절 | 존중하되 인물별로 다른 아쉬움·거리·자기 행동 | 거절을 벌점화하지 않고 모두 같은 위로 문장으로 끝내지 않음 |
| 사후 변화 | 다음 만남에서 행동/부탁/의사 재확인 1회 이상 | 기록·호감 변화 외 장면에서 관측 |
| 다중 관계 | 고백·독점 기대·다자 합의를 분리 | 관계 둘 이상이라는 이유만으로 무목격 질투 발생 금지 |

특별 장면마다 진입 조건·대체 경로·주도권·허락·거절·후속 장면을 메타데이터에 둔다. 현재 `romance.ts`의 기존 8개 목록을 새 히로인 실제 장면과 맞추는 작업이 필요하다. 기존 표를 삭제하거나 현재 감정 조건을 일괄 낮추는 방법은 권고하지 않는다.

## 독창적인 웹소설 서술 기법

사용자의 참고 요청은 특정 작품의 고유 문장·표현을 복제하는 방식으로 적용하지 않는다. 현재 NARRATIVE_STYLE_GUIDE의 해리 관찰 원칙 안에서 다음을 권고한다.

| 항목 | 실제 원고에서 적용할 기준 | 검수 방법 |
|---|---|---|
| 길이·리듬 | 정보 문장 뒤 짧은 행동/반응; 모든 문장을 단문으로 쪼개지 않음 | 긴장 장면과 일상 장면의 호흡이 실제로 다르게 읽힘 |
| 정보 타이밍 | 관찰→잠정 해석→선택→추가 단서 | 확인 전 원인을 사실형으로 말하는 대사를 점검 |
| 어휘 | 촉각·소리·물건의 구체어를 우선, 추상적 감정 결론 절제 | 행동 뒤 같은 감정을 다시 설명한 문장 표시 |
| 전환·반전 | 시각·장소·소지품을 먼저 고정하고 기존 단서를 재해석 | 새 정보가 이전 선택을 사후에 무효화하지 않음 |
| 말투 | 헤르미온느 조건/수정, 지니 직구/속도, 루나 구체 관찰, 판시 거래/우위, 드레이코 경계/실무 | 이름을 가린 대사 비교; 모두 허락 안내문처럼 말하지 않음 |
| 감정 전달 | 행동·시선·침묵 뒤 판단을 남겨 둠 | 타인 내면의 단정은 인용/관찰 근거 또는 해리의 추정으로 한정 |
| 제한 시점 | 보지 않은 현장은 발신자 있는 보고로 전환 | 해리의 KN 시점과 문장 확정도가 맞음 |

원고 적용 대상은 우선 Ch2 친밀/거절 5인 각 1장면과 Ch3 도입 5개다. 문체 수정과 조건/효과 변경을 분리해 검토하며 기존 데이터와 선택 ID를 유지한다(B11).

## 객관 문제와 품질 제안 분리

- 객관 인과 문제: 금요일 밤을 일요일에 어젯밤으로 말함(B02), Ch3 수요일에서 월요일 구금으로 복귀(B01), 봉투를 안 가진 연락책에게서 봉인을 확인하는 초안(B03).
- 기능 공백: pause 시간 0, 실제 그림 자세·시선 변형 제한, 새 특별 장면 메타데이터 누락(B06/B09).
- 품질 제안: 심리 해설 절제, 인물별 거절 리듬, 독립 목표, 관계 사후 행동(B05/B11). 사용자의 선호 수준을 확정 설정 위반으로 바꾸지 않는다.
- 화면 검증/이미지 비교는 미수행이다. 실제 샷이 매력적인지·그림이 레퍼런스와 맞는지·모바일에서 얼굴이 잘리는지는 확인 불가다.

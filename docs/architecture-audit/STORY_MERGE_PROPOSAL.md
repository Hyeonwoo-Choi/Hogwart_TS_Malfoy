# Ch1~14 통합 구조 권고

2026-10-22 감사 제안. [비교와 기준 버전](ARCHITECTURE_COMPARISON.md)을 전제로 한다. 원본 대체·정본 확정·새 플래그 예약이 아니다.

## 두 층의 분기

1. 개발용 장기 축: 기록 / 팀 / 성의 공간 / 사회적 거래 / 불안정 마법. Claude의 복선 추적 틀을 유지한다.
2. 챕터별 사건: 그때의 인물 목표, 증거, 충돌, 선택, 손실, 결산을 Codex 매트릭스에서 가져온다. 같은 A라도 언제나 헤르미온느와 연애하는 사건은 아니다.
3. 관계는 사건 출입권과 분리한다. 동일 사건에서 우정·갈등·연애 변형이 가능하고, 거절해도 사건 결말을 볼 수 있다.
4. 공통 세계 사건, 해리의 현장 체험, 해리가 아는 사실을 별도로 관리한다. 발생한 사건을 모든 플레이어가 자동으로 아는 것은 아니다.

한 챕터에 긴 주 사건 1+선택 보조 1을 권고한다. 남은 축의 인물도 짧은 자율 행동·게시판·전언으로 움직이되 목격/발신자 없이 지식을 부여하지 않는다. 일반 경로는 낮은 능력치·관계 0에서도 종단을 보장한다.

## Ch2 적용 순서와 예산

- 첫 단계: 기존 A~D 장면·ID·현재 진행을 보존하고 각 경로에 고유 결산 1개를 명확히 한다. 단순 수치 변화 대신 원본 인계, 훈련 중단, 출입구 사용권, 본인 명의 진술처럼 사건 결과를 다르게 한다.
- 두 번째: 기존 일반/드레이코 경로를 삭제하지 않고 E의 자연 진입 훅을 추가한다. 관계와 관계없이 폭발 흔적→관찰/접촉/도움 요청을 고를 수 있게 한다.
- 위험한 선택도 허용한다. 부상·징계·도구 손실·타인의 거절 중 맥락에 맞는 후속을 쓰고, 더 위험하면 항상 더 좋은 단서를 받는 구조는 피한다.
- Codex 30장면은 전체 제작 확정량이 아니다. Claude 후속 장면과 중복되는 도입은 합치고 결산·후폭풍을 먼저 제작한다.
- 9/25 조사, 9/27 관계, 9/28 경기·사고, 9/29 후속을 시간순으로 배치한다. 경로 파일 전체를 연속 호출해 날짜가 되감기면 안 된다.
- 새 Q-11~17·KN/FLAG 이름은 문서 초안이다. 구현 전에 BRANCH_MAP의 단일 정의·기존 키 충돌·최소 1후속 참조를 검증한다.

## Ch3 연결 계약

1. `ch3_open`의 날짜·제목·구금 본문 경계를 명확히 분리한다. 월요일 아침 훅→당일 선택→월요일 저녁 구금의 순서를 유지한다.
2. `v2c3_route`의 우선순위는 큰 후폭풍→주 사건→일반으로 명시하고 다중 조건이 참일 때의 사례를 테스트한다. 미구현 `FLAG_P2_UNSTABLE`만으로 E 진입을 보장했다고 쓰지 않는다.
3. `v2c3_wD_C`의 수요일 결과는 수요일에 별도 후속으로 재생하거나 월요일 행동 결과로 다시 쓴다. 날짜만 수요일로 바꾸고 월요일 구금으로 돌아가는 해결은 금지한다.
4. 야간 훈련은 구금 종료·운동장 폐쇄·통금과 대조한다. 명시적 허가 장면이 없으면 아침/낮으로 옮긴다.
5. `v2c3_join`을 실제 다음 장면으로 연결한다. 기존 `END`의 프로토타입 종단을 본편 종료처럼 남기지 않는다.
6. 검사: 새 게임→Ch2→Ch3 종단의 자연 플레이와 프로토타입 직접 진입 검사를 별도 표기한다. A~E·일반, 거절·저능력치·갈등의 최소 증인을 보관한다.

## 지속 상태와 비용 제한

현재 플래그·선택 이력·지식을 입력으로 유지한다. 축별 ARC/STANCE/OUT는 조회용 요약이며 원래 이력을 대체하지 않는다. `case`·`arcs`·평판의 새 저장 필드는 필요성이 검증될 때 별도 호환성 작업으로 도입한다.

| 보존해야 할 사실 | 최소 기록 | 뒤에서 달라져야 할 것 |
|---|---|---|
| 발견과 추정 | 누가/언제/어디서 무엇을 봤는지 | 수첩 문구·조사 질문·단정 가능 범위 |
| 약속 | 대상·범위·기한·이행/파기·수습 | 실제 부탁·자료 접근·상대의 거절 |
| 동의 | 정보 열람/공개/신체 접근의 별도 허락 | 다음 장면에서 새 행동은 다시 확인 |
| 소문 | 발신자·전달·목격과 시각 | 알 수 있는 인물만 반응 |
| 사건 결과 | 해결/악화/보류+남은 피해 | 다음 사건의 인력·길·물건·증거 |
| 관계 | 단계·호감 외 당사자의 현재 의사 | 접근/보류/거절/관계 재협상 |

장면 조합 전체를 쓰지 않는다. 합류 본문+제한된 반응 블록을 재사용하되 경로별 고유 선택 1개·즉시 비용 1개·다음 챕터 후속 1개를 수용 기준으로 둔다. 이것은 새 수치 보상 예산이 아니라 장면 검수 기준이다.

## 승인 전 남겨 둘 선택

- 탑 직접 체험을 전 경로 필수로 유지할지, 세계 사건만 공통으로 둘지는 정본 결정 항목이다.
- 새 사건 70개는 설계 후보이지 전량 구현 계약이 아니다. 기존 Ch3~8을 어느 정도 변형할지도 2챕터 검토 단위로 결정한다.
- 미관측률을 낮추려고 관계 문턱부터 내리지 않는다. 목표 성향·가능 날짜·선택 정책·진입 자격의 분모를 먼저 분리한다.

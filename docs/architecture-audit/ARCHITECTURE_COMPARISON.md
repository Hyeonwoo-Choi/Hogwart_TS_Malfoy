## 충돌과 선택

### C01 사건 축과 인물 고정 — P1 설계 결정

- Codex: 챕터별 사건을 새로 정의한다. 자료 소유·선발·이동권·증언·관계 경계가 독립된 목적이며 A~E는 영구 연애 루트가 아니다.
- Claude: AXES 9~14행에서 기록/팀/성의 이상/슬리데린/불안정 마법을 고정한다. 대표 인물도 반복 배치한다.
- 구현: `v2c2p.ts`의 연구·경기·계단·편지 4경로가 있고 E 독립 경로는 아직 없다. Ch1에서 드레이코를 택해도 Ch2 D로 연결된다.
- 권고: 고정 축을 개발용 분류로 쓰고 챕터별 사건 목적·해결 결과는 Codex 방식으로 둔다. 한 인물을 축의 독점 입장권으로 만들지 않는다.
- 근거/포기: 상태 조회·복선 추적을 단순화하면서 인물 독립성을 살린다. 챕터마다 완전히 자유로운 축 재편의 장점 일부를 포기한다.

### C02 공통 사건과 강제 체험 — P1 설계 결정

- Codex: Ch6 흉터·Ch8 가족 편지는 해당 직접 경험 경로에서만 알며 Ch13에는 인계·호송·봉쇄·보호·탑을 병행한다.
- Claude: 마스터 23~39행과 AXES 24·26·31행은 T-01/K-14/탑을 공통 필수로 놓는다. 다른 축은 탑을 위한 지원이 되기 쉽다.
- 구현: 기존 Ch3~8은 드레이코 중심 공통 골격이 남아 있다. 후반 9~14 새 다중 사건은 설계이며 구현 완료로 볼 수 없다.
- 권고: 세계에서 일어난 사건과 해리가 직접 체험·학습한 사실을 분리한다. 탑 사건은 공통 세계 결과로 유지할 수 있지만 해리의 현장 배치는 선택 가능하게 한다.
- 근거/포기: 제한 시점과 경로별 절정을 확보한다. 모든 플레이어가 핵심 비밀 공개를 같은 장면으로 보는 연출 효율은 줄어든다. 기존 엔딩 의미를 바꾸려면 별도 승인 판단이 필요하다.

### C03 Ch2 A~E의 확장 규모 — P2

- Codex: 5경로×6장면, 각 조사에 독립 해결 선택·비용·후속을 둔다. E는 비활성 시료의 감독하 관찰이다.
- Claude: 기존 A~D에 Q-11~14 후속 장면을 더하고 E에 Q-15~17을 추가한다. 위험 조사·부상·스네이프 주시로 사건성을 높인다.
- 구현: 기존 Q/L 장면은 실제 플레이 가능하지만 두 문서의 새 30장면·새 Q-11~17 전체는 구현된 것이 아니다.
- 권고: 기존 장면을 보존하고 각 경로의 독립 결산 1개부터 보강한다. E는 위험한 선택과 비접촉·도움 요청 대안을 함께 두고 원인 단정은 늦춘다.
- 근거/포기: Claude 안의 추진력과 Codex 안의 증거 경계를 결합한다. 즉시 30장면 전량 제작과 위험 선택의 빠른 마법 해답을 포기한다.

### C04 Ch3 프로토타입 재사용 — P1 연결 전 해결

- Codex: 징계 진술·복귀 심사·우회 통행·증언 보호·사생활 경계를 독립 사건으로 제안한다.
- Claude: `v2c3p.ts:14~21`이 Ch2 후폭풍→A~D→일반으로 분기한다. 새 봉투·공지·카드·흔적 도입은 재사용 가치가 있다.
- 구현: `scenario.ts`에 등록됐지만 진입 간선은 없다. `v2c3_join:239`는 END이며 `v2c3proto.test.ts:68`은 상태의 scene을 강제로 바꾼 뒤 70행에서 합류 전까지 검사한다.
- 권고: 도입 원고는 재사용하고 해결·이월 결과를 보강한다. `ch3_open` 구금부 분리와 실제 종단 연결 후 새 게임→Ch3 종단 테스트를 추가한다.
- 근거/포기: 작성된 장면을 살리면서 연결 검증을 확보한다. 프로토타입 테스트 통과를 본편 자연 도달성 증거로 사용하는 편의는 포기한다.

### C05 상태 요약과 약속 기억 — P1 설계 결정

- Codex: 증거 출처·보관·허락·약속·배치를 구별하는 상세 상태 모델을 제안한다.
- Claude: AXES 42~49행은 축당 ARC/STANCE/KN/OUT 4슬롯만 이월하고 상세 선택 직접 참조를 제한한다. 구현 계획의 `arcs`는 아직 제안이다.
- 구현: 현재 실제 조건은 기존 플래그·`CH_...` 선택 이력·지식·bond를 사용한다. 새 case/arcs/rep 자료구조가 엔진에 구현됐다고 볼 근거는 없다.
- 권고: 4슬롯은 요약으로 쓰되 원래 선택·약속·거절·정보 출처를 지우지 않는다. 기존 ID를 그대로 읽는 어댑터부터 설계한다.
- 근거/포기: 유지 비용을 줄이면서 동의·배신의 차이를 보존한다. 모든 장면을 4슬롯만으로 판단하는 극단적 단순함과 상세 필드 전량 도입을 모두 피한다.

### C06 장기 목표·관계의 비중 — P2

- Codex: 헤르미온느 공저권, 지니 팀 자율성, 루나 제보자 보호, 판시 독립 명의·거처, 드레이코 자신의 판단을 사건 절정으로 둔다.
- Claude: 고정 축의 장기 복선 연결은 선명하지만 후반 지원 행동이 드레이코·캐비닛으로 수렴하기 쉽다. Ch3 상세 91행의 “연애 대상 아님”은 해당 챕터 한정인지 불명확하다.
- 구현: `v2c2r.ts`에 인물별 접근·거절 변형이 있다. 존재 자체는 충족하지만 다음 챕터의 행동 결과까지 충분히 연결됐다는 증거는 부족하다.
- 권고: 인물별 자기 목적의 결정·해리 없이 한 행동·해리가 거절할 수 있는 부탁을 2챕터 단위로 둔다. 드레이코 연애 가능성은 전체 폐기하지 않고 Ch3의 속도 제한으로 명확히 한다.
- 근거/포기: 캐릭터를 보상이나 조사 도구로 만들지 않는다. 한 중심 미스터리로 모든 인물의 비중을 해결하는 제작 효율은 줄어든다.

### C07 복선의 확정도·회수 — P1

- Codex: 관찰→가설→검증→확정 단계를 나누고 Ch6 이전 흉터 지식과 타인의 속내를 차단한다.
- Claude: N-01~11 회수표가 구체적이다. 다만 Ch2 도착 심리의 마법 일치 단정, Ch8 “맹세의 법”, Ch2 열두/열세 소리와 Ch13 회수 사이의 공개 수준을 조정해야 한다.
- 구현: 새로운 N 복선 전체가 실제 대사·KN 플래그로 구현된 것은 아니다. 설계 위험을 현재 비밀 유출 버그로 단정하지 않는다.
- 권고: 각 복선에 관찰자·지식 수준·첫 사용·최종 회수를 기록한다. 일반 맹세 법칙과 실제 인물의 맹세 사실은 별개로 둔다.
- 근거/포기: 회수 계획의 장점을 유지하면서 첫 체험의 추론 여지를 보존한다. 초반에 원리를 명확히 설명하는 속도는 늦어진다.

### C08 제작 상한과 합류의 의미 — P2

- Codex: 주 사건 1+긴 보조 사건 1. Claude: 최대 3활성 축, 축당 3~4장면. 둘 다 폭증을 억제하나 상한은 다르다.
- 구현: 한 번의 Ch2 저녁에는 관계 장면 하나만 재생된다(`v2c2r.ts:5~8`). 다중 관계 요청과 충돌할 수 있어 다음 기회 보장이 필요하다.
- 권고: 주 사건 1+선택 보조 1을 긴 장면 상한으로 두고 나머지는 짧은 독립 행동/전언으로 남긴다. 합류 전 고유 선택과 합류 후 다른 반응을 필수로 둔다.
- 근거/포기: 공통 날짜·배경을 재사용하되 결과를 보존한다. 한 회차에 세 축의 장편을 모두 소화하는 양은 줄어든다.

### C09 Ch2 상세 초안의 인과 — P1 원고 수정 전

- Claude Ch2 상세 111~119행: 봉투가 판시 소매로 옮겨간 뒤 떠난 연락책을 따라가 같은 봉투 인장을 본다. 연락책도 이미 떠났는데 A 비용에는 그가 듣는다고 적혔다.
- Codex는 증거 보관자·위치·열람 권한을 분리한다. 현재 이 새 장면은 미구현이다.
- 권고: 연락책이 머무는 시간 또는 별도 회신 봉투를 명시하고 관찰 대상 소유자를 고정한다. 몰래 따라가기의 긴장은 유지하되 없는 물체에서 얻는 단서는 삭제한다.
- 포기: 빠른 추적 장면 전개 일부. 대신 공정한 단서와 실행 가능한 분기를 얻는다.

# V2_ROMANCE_DIRECTION — 성숙한 로맨스 연출 지침

> 상위: [V2_DESIGN.md](V2_DESIGN.md), 규칙: [V2_RELATIONSHIP_ROUTES.md](V2_RELATIONSHIP_ROUTES.md), 문체: [NARRATIVE_STYLE_GUIDE.md](NARRATIVE_STYLE_GUIDE.md), 장면 지침: [ROMANCE_SCENE_GUIDE.md](ROMANCE_SCENE_GUIDE.md). 모든 주요 학생 인물은 성인 AU이며 해리 1인칭 관찰 시점을 유지한다.

## 1. 강도와 원칙
- 수업·탐험·퀴디치·일상은 각자의 분위기를 유지한다. 강한 로맨스는 **이전 관계 이력(신뢰·단계·함께한 사건)이 충족된 뒤에만** 배치한다(`v2c2r.ts`의 친밀 조건).
- 긴장의 재료: 서로의 반응을 떠보는 말, 장난과 도발, 갑작스러운 거리 변화, 평소와 다른 말투, 진심을 확인하는 질문, 질투를 숨기거나 드러내는 순간, 자존심 때문에 솔직하지 못한 상황, 약속을 지킨 뒤의 특별함, 갈등 뒤 화해, 약점을 알게 된 뒤의 신뢰.
- 신체 접촉(손잡기·키스)은 말로 하는 허락이 있는 선택에서만 일어난다. 더 깊은 장면은 장면 전환·여운으로 처리하며, 원치 않는 행동을 강행하는 것을 성공으로 그리지 않는다. 거절·보류는 처벌하지 않는다.
- 선정적 묘사 확대는 하지 않았다. 구현된 가장 강한 장면은 짧은 입맞춤과 손을 잡는 장면이다.

## 2. 인물별 방향과 챕터 2 구현 [구현: `ch2_eve_i_*`·`ch2_eve_t_*`, 경로 행사]
| 인물 | 방향 | 구현된 장면의 핵심 |
|---|---|---|
| 판시 | 도발·심리전·체면. 유혹 담당이 아니라 기숙사 정치와 가문의 압박을 가진 사람 | 복도에서 한 걸음씩 다가와 한 뼘 앞에서 멈추고 "도망칠 거야?"를 묻는다. 해리가 움직이지 않자 시험하는 쪽이 먼저 흔들린다(클로즈업 + 줌 큐 + 정적). 물으면 "묻는 것도 나쁘진 않네" 하고 직접 허락, 소문 나면 끝이라며 비밀을 요구. 질투는 "상황 정리"라고 부정 |
| 지니 | 직설적 밀당·대등. 기다리지 않고 자기가 정한다 | 골대 아래에서 "너 나 좋아해?"를 묻고 한 뼘 앞에서 웃다가, 정면으로 답하자 먼저 물러나 당황한다. 키스는 경기 끝나고 "내가 정하는 속도로". 변명하면 "지켜 주지 말고 지켜봐" |
| 헤르미온느 | 절제와 대비. 규칙과 감정의 충돌, 분석하다 당황 | 접은 양피지에 "가설 / 근거 / 검증 방법: ?"을 적어 건넨다. 손을 잡아도 되냐고 묻자 "대상의 동의가 가장 중요하다"며 먼저 손가락을 올린다. 규칙 위반을 놓고는 정직과 정확함 사이에서 화를 낸다 |
| 루나 | 예상 밖 거리감·솔직함, 태연함이 진심에서 온다 | "키스하고 싶어진다는 건 어떤 기분이야?"를 날씨 얘기하듯 묻고 "싫다는 말도 정보니까"라며 허락을 구한다. 입맞춤 뒤 신발끈을 세 번 다시 묶는 것으로 감정을 보여 준다. 대신 말해 버린 일에는 "내 이야기를 대신 하는 건…"이라는 경계 |
| 말포이 | 자존심·경쟁·취약함. 변신 설정·환영 규칙을 건드리지 않는다 | 내기를 도발하는데 눈 밑 그늘을 지적받자 반박할 문장을 찾지 못한다. 접촉은 어깨가 스치는 정도로만. 변신의 비밀은 이 장면들에서 언급하지 않는다 |

## 3. 레퍼런스 이미지의 연출적 반영 (이미지 자체는 사용·복제하지 않음)
참고한 것은 **구도와 거리감으로 표현되는 주도권**이다. 특정 신체 부위를 반복해 강조하지 않는다.
| 레퍼런스 특징 | 엔진 표현 [구현] |
|---|---|
| 낮은 시점에서 올려다보는 존재감, 가까워지는 인물 | 자세 `near`(확대 1.1) · `close`(1.2, 클로즈업) |
| 상대 반응을 즐기는 여유, 물러남 | 자세 `back`(0.9) · `tilt`(고개 갸웃, 장난스러움) |
| 시선만으로 전달되는 우위 | 시선 `front/side/down/away` 지정, 대사별 표정 |
| 짧은 동작 강조, 컷 전환 | 줌 큐(`cue('zoom')`), 조명 변경 |
| 침묵·대사 전 지연 | `cue('pause')`(진행을 막지 않는 정적 표시), 짧은 "…" 대사 |
- 인물별 구성이 달라야 한다: 판시(다가옴 + 클로즈업 + 줌), 지니(좁혔다가 웃으며 물러남), 헤르미온느(다가왔다 당황해 후퇴), 루나(기울임 + 태연한 근접), 말포이(도발 후 붕괴 → 후퇴·시선 회피). 테스트가 접근·후퇴 존재와 구성의 차이를 확인한다.
- 움직임 감소 설정: 전환 애니메이션이 꺼지고 최종 위치만 적용된다(CSS). 연출 도중 저장·불러오기 시 자세·시선이 복원된다.
- **미구현**: 대사 표시 전 지연 시간 제어(`cue('pause')`는 표시일 뿐 대기시간이 아님), 선택지 지연 등장, 실제 일러스트(아래 3.1).

# CHARACTER_LONG_ARCS — 인물별 독립 서사와 관계 변화

> 상위: [STORY_MASTER_BRANCHES.md](STORY_MASTER_BRANCHES.md). 기존 인물 설정: [V2_HEROINES.md](V2_HEROINES.md), [GAME_BIBLE.md](GAME_BIBLE.md). 모든 주요 학생은 성인 AU. 해리 1인칭이므로 "해리 없이 진행되는 행동"은 **해리가 나중에 듣거나 단서로 마주치는 형태**로만 보인다.
> 규칙: 인물은 연애 보상이 아니다 — 해리가 아무도 따라가지 않아도 아래 "혼자 진행되는 행동"은 일어난다(소식·소문·짧은 장면으로 노출).

## 헤르미온느 그레인저 — 축 A (금지된 기록)
| 항목 | 내용 |
|---|---|
| 원하는 것 | N.E.W.T. 수석 + "규칙을 어기지 않고도 진실에 닿을 수 있다"는 증명 |
| 두려워하는 것 | 아는 것이 아니라 **알게 되는 것**(맞을까 봐 말하지 못한 쌍 가설), 규칙과 정의가 갈라지는 순간 |
| 숨기는 것 | 제한 구역 서명 요청이 거절당할 때의 오래된 모욕감, 말포이가 같은 수리서를 반복 대출한다는 사실(Ch3 발견) |
| 혼자 진행 | 대출 기록 대조, 룬 논문, 맥고나걸과의 면담(해리의 보고 여부와 무관하게 의심은 쌓임) |
| 가까워질 때 | 분석하려다 당황, 가설 형식으로 감정 표현("검증 방법: ?"), 손을 잡기 전 동의를 확인 |
| 갈등·거절·화해 | 규칙 위반에 침묵하는 대신 **변명 없는 설명**을 요구. 질투는 "서운함"으로 먼저 나오고 단계 3+연애일 때만 질투. 화해 = 순서대로 말하기 |
| 가치관 | 규칙 절대주의 → "규칙은 사람을 위한 도구, 다만 어길 때는 설명한다"로 이동(Ch5 증거와 정의, Ch10 최후통첩에서 시험) |
| 마일스톤 | Ch2 책 → Ch3 대출 기록 → Ch4 쌍 가설 → Ch5 포장지 문양 → Ch8 맹세의 법 → Ch10 **기한 후 교사에게 가겠다** → Ch11 고백/거절 → Ch12 법·규정 접근 → Ch13 와드 해제 지원/거절 |

## 지니 위즐리 — 축 B (경기와 팀)
| 항목 | 내용 |
|---|---|
| 원하는 것 | 이름이 "해리의 친구"가 아니라 **자기 성과**로 남는 것, 주장 |
| 두려워하는 것 | 보호받는 사람이 되는 것(작아지는 것), 가족의 그늘(형들) |
| 숨기는 것 | 새벽 연습(7층 창 그림자 목격, Ch2), 어깨의 오래된 통증 |
| 혼자 진행 | 팀 선발·연습 일정 조정, 후치·케이티와의 경기 전략, 론의 슬럼프를 몰래 돕기 |
| 가까워질 때 | 직설("너 나 좋아해?"), 장난스러운 거리 좁히기 후 정면 응답에 오히려 먼저 물러남, 키스는 "내가 정하는 속도" |
| 갈등·거절·화해 | 해리가 **대신 정하는 것**에 가장 민감. 감점·소문(Ch3)에는 팀 규율을 먼저 말한다. 화해 = 같이 서자 / 경기 후 한 판. 거절은 "마음이 바뀌어도 내가 정한다"로 받아들임 |
| 가치관 | 승패 → 팀 안의 신뢰(Ch7 주장), 개인 → 책임(Ch13 소동에서 지원) |
| 마일스톤 | Ch2 첫 골·창 번쩍임 → Ch3 팀 반발(해리의 감점) → Ch5 케이티 공백 → Ch7 주장 선거 → Ch8 론 → Ch10 경기 충돌 → Ch11 고백/거절 → Ch13 경기 소동 지원 |

## 루나 러브굿 — 축 C (성의 이상)
| 항목 | 내용 |
|---|---|
| 원하는 것 | 이상한 것을 **이상한 채로 이해**하는 것, 아버지의 신문이 비웃음거리가 아닌 세계 |
| 두려워하는 것 | 자기 이야기를 남이 대신 말하는 것, 소문이 아버지에게 번지는 것 |
| 숨기는 것 | 숫자 세기에서 이미 알아챈 것(그날 7 이후), 해리가 숨기는 것이 있다는 직관(말하지 않음) |
| 혼자 진행 | 호수와 성벽의 소리·불빛 기록, 계단 지도, 신문 투고 |
| 가까워질 때 | 예상 밖 질문("어떤 기분이야?"), 태연함, 허락을 묻고 거절도 정보로 받음, 감정은 사소한 행동(신발끈)으로 |
| 갈등·거절·화해 | 대신 말한 일에 "소리 안 나게 아픔". 화해는 사과의 소리를 인정. 거절 시 "질문은 거절당해도 질문", 우정 유지 |
| 가치관 | 설명하지 않는 믿음 → 필요할 때 **같이 정하는** 협력(Ch12 증인) |
| 마일스톤 | Ch2 계단·열두 번 → Ch3 막힌/열린 계단 → Ch4 증언(K-08C) → Ch6 편견 → Ch7 호수 빛 → Ch10 쌍 위치 → Ch13 열세 번째 소리 |

## 판시 파킨슨 — 축 D (슬리데린)
| 항목 | 내용 |
|---|---|
| 원하는 것 | 드레이코의 곁(충성과 보호), 슬리데린에서 **자기 자리**를 자기가 정하는 것 |
| 두려워하는 것 | 체면을 잃는 것, 드레이코가 자신을 영영 보지 않는 것, 가문의 결정이 자신을 지나쳐 가는 것 |
| 숨기는 것 | 새벽에 따라간 계단 아래(Ch2 고백), 편지 세 통, 별관 끝 방 열쇠 |
| 혼자 진행 | 4학년 연락책과의 거래, 드레이코의 부재 알리바이 만들기, 슬러그 클럽 정치 |
| 가까워질 때 | 도발과 시험(한 뼘 앞에서 멈춤), 물으면 "묻는 것도 나쁘지 않네", 소문을 지켜 달라는 요구 |
| 갈등·거절·화해 | 약속 위반(폭로)은 가장 치명적: 공손한 거리 두기. 질투는 "상황 정리". 화해 = 약속을 다시 세우는 것(행동으로) |
| 가치관 | 체면 → 선택한 충성, 독립 루트 가능성(드레이코 지지자/경쟁자 중 하나로 남음) |
| 마일스톤 | Ch2 편지·마감 → Ch3 연락책·확인 요구 → Ch5 공개 고발 분노 → Ch6 흉터 → Ch10 압박 절정 → Ch11 독립 루트 판단 → Ch12 슬리데린 내부 통로 → Ch13 안전한 방 |

## 드레이코 말포이 — 축 D·E의 대상, 공통 필수의 주연
| 항목 | 내용 |
|---|---|
| 원하는 것 | 가족을 지키는 것, 자기 방식으로(도움받는 것이 아니라 스스로 해내는 것) |
| 두려워하는 것 | 실패가 어머니에게 닿는 것, 노출, 도움받는 약함, 변한 몸이 사람들 앞에서 해석되는 것 |
| 숨기는 것 | 임무·캐비닛·흉터·변화. 변화 이후에는 **몸과 정체성에 대한 자기 감정**(자기수용 ≠ 애정) |
| 혼자 진행 | 7층 작업(수·토), 환영 주문 연습, 편지 소각, 폐쇄술 거부 |
| 가까워질 때 | 도발이 먼저, 예상 밖 반응에 무너짐(말문 막힘), 접촉은 어깨가 스치는 정도, 비밀 공유가 신뢰의 단위 |
| 갈등·거절·화해 | 멱살·폭로 같은 정면 충돌에도 "가짜 아닌 주먹"을 인정하는 정직. 도움의 방식이 문제(대신 정하면 반발). 화해 = 허락을 구하는 방식 |
| 가치관 | 가문 중심 → "내 이름으로" 서기, 환영(남의 눈)과 진짜 모습(나) 사이의 선택은 **그가 정한다** — 해리는 치료·원상복구의 주체가 되지 않는다 |
| 마일스톤 | Ch2 변화·환영 → Ch3 징계 속 비밀 유지 → Ch4 방 → Ch6 흉터(T-01) → Ch7 폐쇄술 거부 → Ch8 편지 → Ch9 시험 → Ch10 완성 → Ch12~13 결단 |

## 론 위즐리 (비공략 조연)
- 원하는 것: 해리의 그림자가 아니라 키퍼로서 인정받는 것. 두려워하는 것: 모두에게 필요 없는 사람. 숨기는 것: 푸딩 농담 뒤의 짧은 웃음(초대받지 못한 서운함).
- 혼자 진행: 키퍼 연습(열한 번 막기), 지니와의 약속, 헤르미온느와의 거리. 변화: 질투를 말로 하는 법(Ch2) → Ch8 슬럼프 K-15 → Ch10 해리의 비밀을 눈치채지만 먼저 묻지 않는다 → Ch13 "친구가 불려 가는 걸 질투하지 않는 어른"이 아니라 질투해도 곁에 남는 사람.

## 편중 점검
- 챕터당 ◎ 경로의 주인공이 서로 다른 인물이다(매트릭스). 드레이코는 공통 필수 장면에서만 주연이고 경로 장면에서는 대상·배경이다.
- 연애 `open`은 챕터 2에서 4개 장면 모두 **명시적 허락 선택**에서만 생긴다. `together`·다자 합의는 Ch11 이후 설계.

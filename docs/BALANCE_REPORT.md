## 2. 비공개 정책
- 선택 전: 능력치 상승·보상·관계 변화·성공 확률·분기 조건을 표시하지 않는다(활동 설명은 상황 묘사만).
- 선택 후: 숫자 팝업 없음. 서술로만("같은 문단을 세 번 읽고서야…"). 지도 우측 능력치 화면은 유지.
- 판정 조건을 만족하지 못한 선택지는 표시하지 않는다(해리가 떠올리지 못한 행동). 조건 문구도 표시하지 않는다.

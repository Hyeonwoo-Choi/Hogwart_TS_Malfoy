# CH1_NARRATIVE_AUDIT — 챕터 1 실제 플레이 흐름 감사와 재설계

> 측정: `SCENARIO`의 v2c1_*·hr1_* 장면을 코드로 집계(대사 수는 화자별 줄 수, 선택 순서는 장면 순서). 작성 시점 구현 기준. 장면의 서사 품질은 사람이 읽어야 안다.

## 1. 실제 흐름(필수 경로)
프롤로그(지니, P-01) → 열차(판시·말포이, K-01) → 감독생 칸(론·헤르미온느, H-02) → 순찰(헤르미온느·루나) 또는 객실(론·루나) → 개학 연회(H-01 판시, H-07 론) → 마법약(K-02) → 경기장(K-03) → **[신규] 화요일 저녁 루나·판시(C1-01·C1-02)** → 화요일 밤 H-08(사건 선택 6지) → 자유 일과 한 주(`hr1_*` 일대일, H-03~H-06 선택적) → 토요일 밤 K-04(드레이코) → 후속 → 챕터 2.

## 2. 인물별 실제 노출(H-08 이전, 필수 경로 기준 화자 줄 수)
| 인물 | 첫 등장 | H-08 이전 일대일 | 해리에 대한 태도가 드러나는 곳 | 평가 |
|---|---|---|---|---|
| 지니 | 프롤로그 | 프롤로그 4줄 + 경기장 8~12줄 | 경쟁자·증인으로 대함, 시간표 다툼 | 충분 |
| 드레이코 | 열차 | 열차·연회·마법약·경기장 다수 | 적대 속의 계산 | 충분(밤 K-04가 정점) |
| 헤르미온느 | 감독생 칸 | 7줄 + 순찰/연회 6줄 | 확신보다 증거를 요구, 무서움을 털어놓음 | 충분 |
| 론 | 감독생 칸 | 5줄 + 객실/연회 3줄, H-07 | 우정, 주전 불안 | 충분 |
| **루나** | 순찰·객실(H-02 분기 모두) | **약 3~4줄, 이름과 말버릇만** | 이름보다 발소리로 알아봄(이 장면은 없었음) | **부족** |
| **판시** | 열차 카메오 | **연회 H-01의 적대적 대면 5줄 하나** | 방어, 시선에 대한 경계(동기·두려움은 H-08 뒤 hr1에만) | **부족** |

## 3. 핵심 문제
1. **일대일로 성격·목적이 드러나는 장면(`hr1_*`)이 모두 H-08 뒤의 선택적 자유 일과에만 있었다.** 가장 가벼운 단서(숫자 소리, 벤치 쪽지)를 고르는 H-08 시점에 루나·판시는 사실상 낯선 사람이었다.
2. H-08 선택지는 의도적으로 익명이다(`blind.test`). 익명 자체는 유지하되, 단서의 출처를 플레이어가 **경험으로** 알고 있어야 선택에 무게가 생긴다.
3. Ch1 선택 중 후속 챕터가 소비하는 것: P-01(4), K-02(17), K-03(12), K-04(11), H-01(12), H-02(14), H-03~H-06(6~9), H-08(RT_* 플래그). **H-07은 챕터 2 이후 소비 0, `FLAG_HR1_HER_PAPER`·`_GIN_CAPTAIN`·`_LUN_LAKE`·`_PAN_MIRROR`도 소비 0**(자유 일과에서 쌓은 관계가 후속에서 사라짐).
4. 선택의 순서: P-01·K-01·H-02·H-01·H-07·K-02·K-03 (7개) → H-08 → 자유 일과(H-03~06) → K-04. 챕터 끝에 선택이 몰려 있지는 않았지만, H-08이 앞의 7개 중 루나·판시에 관한 선택이 하나도 없는 상태에서 나온다.

## 4. 수정 우선순위와 이번 구현
1. (구현) 루나·판시의 H-08 이전 일대일 장면 — `v2c1_tue*`(src/data/v2c1x.ts). 루나: 이름이 아니라 걸음으로 해리를 알아보고, 소리를 혼자 세면 진짜인지 구분이 안 된다며 같이 들어 달라고 청한다. 판시: 같은 사람을 세고 있지만 이유는 "걔가 무너지면 제일 먼저 맞는 사람이 나"라는 계산이며, 서로 아는 걸 한 번에 하나씩 교환하자고 제안한다.
2. (구현) 작은 선택 두 개를 H-08 앞으로 분산: C1-01(루나: 같이 센다/먼저 묻는다/내일 다시), C1-02(판시: 하나 내놓는다/먼저 달라/직접 듣겠다). 관계를 맺지 않는 선택도 정상 진행.
3. (구현) H-08 안내문이 그 경험을 이름 없이 돌이켜 본다(조건 줄). 선택지·키·플래그는 그대로.
4. (구현) 후속 소비: hr1 루나·판시 첫 일대일, 챕터 2 루나·판시 경로 진입, 론(H-07)·`FLAG_HR1_*` 챕터 2 진입 줄, 수첩(`ch1Records.ts`). 새 상태는 모두 소비처가 있다.
5. (미구현) 헤르미온느·지니·론·드레이코는 필수 경로 안에 이미 성격과 해리에 대한 태도가 드러나므로 장면을 늘리지 않았다. K-04 직전 정보량과 H-02 분기별 노출 차이(순찰=루나 첫 만남과 헤르미온느의 두려움, 객실=론의 두려움과 루나)는 의도된 비대칭으로 둔다.

## 6. 2차 개선: 인물 애착과 의미 있는 분기 (이번 구현)
Antigravity의 Ch1 플레이테스트 보고서는 작업 시점에 저장소에서 찾지 못해 기다리지 않고 진행했다. 아래는 코드 조사와 자동 플레이 근거만 반영한 것이다(인물이 매력적인지는 사람이 읽어야 안다).
| 인물 | 이미 인상적인 장면 | 부족했던 연결 | 이번 변경 |
|---|---|---|---|
| 헤르미온느 | 순찰·연회에서 털어놓는 두려움, 논문 | 능력을 인정받는 길과 개인적으로 신뢰받는 길이 구분되지 않음(H-03은 함께 읽기/비판/물러남) | H-03 D(틀려도 괜찮다 → 열두 번 고친 첫 문단을 처음 보여 줌), B에 `FLAG_C1_HER_RESPECT`. 챕터 2 경로 진입에서 서로 다른 말 |
| 지니 | 프롤로그·경기장·주장 목표 | 해리의 관심 없이도 주도하지만, 해리가 동등하게 겨루는 선택이 없음 | H-04 D(내기): 지니가 진 값을 직접 치르고 "오빠가 이긴 거야"라며 선을 긋는다 |
| 루나 | 이름보다 걸음으로 알아봄(1차 개선) | 의심했을 때의 반응, 다른 사람을 읽는 방식이 단서에 머묾 | C1-01 D(의심), 그녀가 말포이의 걸음을 "숨으려는 걸음·겁내는 걸음"으로 구분해 듣는 장면 |
| 판시 | 거래 제안과 두려움(1차 개선) | 협상·거절 시 태도 차이가 약함 | 먼저 달라고 되받으면 "계산이 정확한 건 인정", 하나만 내놓으면 "정확히 골랐네", 거절은 "정직한 거절은 받아 둔다" |
| 론 | 객실·공지 앞의 불안 | 반응 담당에 머묾 | `v2c1_tue_ron`(C1-03): 론이 "눈빛을 모은다"며 해리의 방식에 동의하지 않는 독립 판단. 받아들임/반박/피함이 각각 K-04 독백·다음 날 아침·챕터 2에 남음 |
| 드레이코 | K-01~K-04 | 판시와 교환한 정보가 K-04에서 쓰일 길이 없음 | K-04 E(들은 말을 꺼냄, `KN_LETTER_DRAWER` 있을 때만): 출처가 하나로 좁혀지고 판시가 챕터 2에서 반응. K-04 A~D·효과·ID 그대로 |
- H-08: 안내문이 앞선 경험(순찰/연회에서 들은 말, 경기장에서 본 것, 수업의 떨림)을 이름 없이 단서와 이어 주며, 어떤 선택지도 이전 선택으로 막지 않는다.
- K-04: 앞선 선택이 독백으로 되살아나고 한 선택지가 추가됐다. 이미 정한 내용을 다시 묻지는 않는다.
- 미구현: 새 이미지·CG(필요한 감정·구도 기록만: `v2c1_tue_luna_d` 루나의 담담한 표정, `v2c1_tue_ron` 론의 체스판 앞 정면 구도, `hr1_hermione_library_1_D` 구겨진 양피지를 쥔 손 클로즈업).
